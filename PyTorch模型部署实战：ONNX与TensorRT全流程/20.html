步骤二：将PyTorch模型导出为ONNX格式

ONNX（Open Neural Network Exchange）是一个开放的模型格式，用于在不同框架间转换模型。

import torch
import torchvision.models as models

# 加载训练好的模型
checkpoint = torch.load('resnet50_imagenet.pth')
model = models.resnet50(pretrained=False)
model.fc = torch.nn.Linear(model.fc.in_features, 1000)
model.load_state_dict(checkpoint['model_state_dict'])
model.eval()

# 创建示例输入张量（符合模型预期输入尺寸）
dummy_input = torch.randn(1, 3, 224, 224, device='cuda' if torch.cuda.is_available() else 'cpu')

# 指定输入输出的名称
input_names = ["input"]
output_names = ["output"]

# 导出模型为ONNX格式
torch.onnx.export(model,
                  dummy_input,
                  "resnet50.onnx",
                  verbose=True,
                  input_names=input_names,
                  output_names=output_names,
                  opset_version=11, # 指定ONNX算子集版本
                  dynamic_axes={'input': {0: 'batch_size'}, # 支持动态batch
                                'output': {0: 'batch_size'}})

print("ONNX模型已导出为 'resnet50.onnx'")

步骤三：使用TensorRT优化ONNX模型

TensorRT是NVIDIA推出的高性能深度学习推理优化器和运行时。它能优化模型，并在NVIDIA GPU上提供低延迟、高吞吐量的推理。

方法一：使用TensorRT Python API

import tensorrt as trt

TRT_LOGGER = trt.Logger(trt.Logger.WARNING)
EXPLICIT_BATCH = 1 << (int)(trt.NetworkDefinitionCreationFlag.EXPLICIT_BATCH)

def build_engine(onnx_file_path, engine_file_path):
    """从ONNX文件构建TensorRT引擎"""
    builder = trt.Builder(TRT_LOGGER)
    network = builder.create_network(EXPLICIT_BATCH)
    parser = trt.OnnxParser(network, TRT_LOGGER)

    with open(onnx_file_path, 'rb') as model:
        if not parser.parse(model.read()):
            for error in range(parser.num_errors):
                print(parser.get_error(error))
            return None

    config = builder.create_builder_config()
    config.max_workspace_size = 1 << 30 # 1GB
    config.set_flag(trt.BuilderFlag.FP16) # 启用FP16精度加速

    engine = builder.build_engine(network, config)
    with open(engine_file_path, "wb") as f:
        f.write(engine.serialize())
    return engine

# 构建并保存引擎
engine = build_engine("resnet50.onnx", "resnet50.engine")
print("TensorRT引擎已保存为 'resnet50.engine'")

方法二：使用命令行工具trtexec（推荐用于生产）

# 基本转换命令
trtexec --onnx=resnet50.onnx --saveEngine=resnet50_fp16.engine --fp16

# 更多优化选项
trtexec --onnx=resnet50.onnx \
        --saveEngine=resnet50_optimized.engine \
        --fp16 \
        --workspace=4096 \
        --minShapes=input:1x3x224x224 \
        --optShapes=input:8x3x224x224 \
        --maxShapes=input:32x3x224x224 \
        --verbose

关键技术与优化点

阶段 关键技术 优化目标 常用工具/库
训练 混合精度训练、梯度累积、数据增强 模型精度、训练速度 PyTorch AMP, Albumentations
导出 算子兼容性、动态维度、版本控制 转换成功率、灵活性 torch.onnx, ONNX Simplifier
优化 层融合、精度校准、内核自动调优 推理延迟、吞吐量 TensorRT, Polygraphy
部署 流水线并行、内存复用、多流推理 资源利用率、系统稳定性 Triton Inference Server, C++ API

核心优化提示： 在TensorRT阶段，务必根据实际部署场景（如最大Batch Size、输入分辨率）配置optShapes和maxShapes，以启用动态形状支持，并充分利用FP16或INT8量化来获得极致性能。

总结与最佳实践

  1. 流程标准化： 建立从训练到部署的标准化流水线，确保可复现性。
  2. 版本管理： 对每个阶段的产物（.pth, .onnx, .engine）进行版本控制。
  3. 验证贯穿始终： 在每个转换步骤后，都必须进行精度验证，确保输出一致。 
    # 简易验证示例：比较PyTorch和TensorRT的输出

# ... 加载PyTorch和TensorRT模型

  4. 性能剖析： 使用nsys或TensorRT内置分析器定位性能瓶颈。
  5. 选择合适精度： 平衡精度（FP32）与速度（FP16/INT8），根据业务需求选择。
