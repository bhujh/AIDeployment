🔒 模型加密

保护模型知识产权，防止模型被非法窃取或篡改。

常用加密技术

  • 对称加密：使用相同密钥加密和解密，如AES。
  • 非对称加密：使用公钥加密、私钥解密，如RSA。
  • 模型混淆：通过重命名节点、插入虚拟节点增加逆向难度。
  • 硬件绑定：将模型与特定硬件（如GPU、安全芯片）绑定。

ONNX模型加密示例

import onnx
from cryptography.fernet import Fernet

# 加载模型
model = onnx.load("model.onnx")

# 生成密钥
key = Fernet.generate_key()
cipher = Fernet(key)

# 序列化并加密模型二进制数据
model_bytes = model.SerializeToString()
encrypted_bytes = cipher.encrypt(model_bytes)

# 保存加密模型
with open("model_encrypted.onnx", "wb") as f:
    f.write(encrypted_bytes)

# 使用时解密
decrypted_bytes = cipher.decrypt(encrypted_bytes)
loaded_model = onnx.load_from_string(decrypted_bytes)

🛡️ 输入验证

确保输入数据符合预期，防止恶意输入导致模型异常或安全漏洞。

验证维度

维度检查内容示例
形状张量维度与大小input.shape == (1, 3, 224, 224)
数据类型张量元素类型input.dtype == torch.float32
数值范围值是否在合理区间0 ≤ input ≤ 1 或 -1 ≤ input ≤ 1
异常值NaN、Infinitytorch.isfinite(input).all()

验证代码示例

def validate_input(input_tensor):
    """验证输入张量"""
    # 检查形状
    expected_shape = (1, 3, 224, 224)
    if input_tensor.shape != expected_shape:
        raise ValueError(f"输入形状应为{expected_shape}, 实际为{input_tensor.shape}")
    
    # 检查数据类型
    if input_tensor.dtype != torch.float32:
        raise TypeError(f"输入数据类型应为torch.float32, 实际为{input_tensor.dtype}")
    
    # 检查数值范围（假设输入是归一化后的图像）
    if input_tensor.min() < 0 or input_tensor.max() > 1:
        raise ValueError("输入值应在[0, 1]范围内")
    
    # 检查异常值
    if not torch.isfinite(input_tensor).all():
        raise ValueError("输入包含NaN或Infinity值")
    
    return True

🚨 异常处理

优雅地处理运行时错误，提供有意义的错误信息，保证系统稳定性。

常见异常类型

  1. 模型加载异常：文件损坏、版本不匹配、加密错误。
  2. 推理异常：GPU内存不足、输入格式错误、计算错误。
  3. 环境异常：依赖库缺失、硬件不支持、权限不足。
  4. 业务异常：超时、并发冲突、资源耗尽。

异常处理策略

class ModelInferenceEngine:
    def __init__(self, model_path):
        try:
            self.model = self.load_model(model_path)
            self.logger = setup_logger()
        except FileNotFoundError as e:
            self.logger.error(f"模型文件不存在: {e}")
            raise
        except RuntimeError as e:
            self.logger.error(f"模型加载失败: {e}")
            raise
    
    def infer(self, input_data):
        try:
            # 输入验证
            validate_input(input_data)
            
            # 推理
            with torch.no_grad():
                output = self.model(input_data)
                
            # 输出验证
            validate_output(output)
            
            return output
            
        except ValueError as e:
            self.logger.warning(f"输入验证失败: {e}")
            return {"error": "invalid_input", "message": str(e)}
        except RuntimeError as e:
            self.logger.error(f"推理运行时错误: {e}")
            return {"error": "inference_failed", "message": "模型推理失败"}
        except Exception as e:
            self.logger.critical(f"未知错误: {e}")
            return {"error": "internal_error", "message": "系统内部错误"}

🔄 故障恢复

确保系统在发生故障后能够自动或手动恢复，保证服务可用性。

恢复策略

策略描述适用场景
重试机制临时故障后自动重试网络抖动、临时资源不足
降级服务返回简化结果或缓存数据模型加载失败、GPU内存不足
备份切换切换到备用模型或服务器主模型损坏、服务器宕机
状态检查点定期保存状态，故障后恢复长时间推理任务

故障恢复架构

最佳实践： 实现监控告警系统，当模型服务异常时自动通知运维人员。定期进行故障恢复演练，确保恢复流程有效。 
class FaultRecoveryManager:
    def __init__(self):
        self.backup_models = {}
        self.retry_count = 0
        self.max_retries = 3
        
    def recover_from_failure(self, error_type, context):
        """根据错误类型执行恢复策略"""
        recovery_strategies = {
            "model_load_failed": self.switch_to_backup,
            "inference_timeout": self.retry_with_timeout,
            "gpu_out_of_memory": self.fallback_to_cpu,
            "corrupted_input": self.use_default_response
        }
        
        strategy = recovery_strategies.get(error_type, self.default_recovery)
        return strategy(context)
    
    def switch_to_backup(self, context):
        """切换到备份模型"""
        model_name = context.get("model_name")
        if model_name in self.backup_models:
            self.logger.info(f"切换到备份模型: {model_name}")
            return self.backup_models[model_name]
        else:
            raise Exception("无可用备份模型")
    
    def retry_with_timeout(self, context):
        """带超时的重试"""
        while self.retry_count < self.max_retries:
            try:
                self.retry_count += 1
                return self.execute_with_timeout(context)
            except TimeoutError:
                self.logger.warning(f"第{self.retry_count}次重试...")
        
        raise Exception("超过最大重试次数")
