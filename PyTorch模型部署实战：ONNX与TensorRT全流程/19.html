1. 单元测试 (Unit Testing)

针对部署流程中最小可测试单元的验证，确保每个组件功能正确。

  • 测试对象：单个函数、类、算子（如Conv2D）、模型转换脚本。
  • 测试重点：输入/输出形状、数据类型、数值范围、边界条件。
  • 常用工具：Python的unittest、pytest。
# 示例：使用pytest测试ONNX模型加载
import onnxruntime as ort
import numpy as np
import pytest

def test_onnx_model_load():
    """测试ONNX模型能否正确加载并运行"""
    sess = ort.InferenceSession("model.onnx")
    input_name = sess.get_inputs()[0].name
    # 构造模拟输入
    dummy_input = np.random.randn(1, 3, 224, 224).astype(np.float32)
    # 执行推理
    outputs = sess.run(None, {input_name: dummy_input})
    # 断言输出形状符合预期
    assert outputs[0].shape == (1, 1000)
    print("✓ ONNX模型单元测试通过")

if __name__ == "__main__":
    test_onnx_model_load()

2. 集成测试 (Integration Testing)

验证多个组件组合后的协同工作能力，关注数据流和接口兼容性。

  1. 模型转换流水线：PyTorch → ONNX → TensorRT 全链路。
  2. 前后端集成：推理引擎与业务API（如Flask、gRPC）的对接。
  3. 多硬件支持：同一模型在GPU、CPU、边缘设备上的行为一致性。

3. 精度测试 (Accuracy Testing)

确保部署后的模型与原始模型在预测精度上保持一致，是部署成功的核心。

测试阶段 评估指标 允许误差 工具/方法
原始模型 (PyTorch) Top-1 Accuracy, mAP, F1-Score 基准值 TorchMetrics, sklearn
中间格式 (ONNX) 输出张量绝对误差 (MAE) ≤ 1e-5 NumPy, ONNX Runtime
优化引擎 (TensorRT) FP32/FP16/INT8 精度损失 ≤ 0.5% (相对) Polygraphy, TRT APIs 
# 示例：对比PyTorch与TensorRT引擎的输出精度
import torch
import tensorrt as trt
import numpy as np

def calculate_accuracy_diff(pytorch_output, tensorrt_output):
    """计算两种引擎输出的精度差异"""
    # 转换为numpy数组
    pt_np = pytorch_output.cpu().numpy() if torch.is_tensor(pytorch_output) else pytorch_output
    trt_np = tensorrt_output
    # 计算最大绝对误差和平均绝对误差
    max_abs_error = np.max(np.abs(pt_np - trt_np))
    mean_abs_error = np.mean(np.abs(pt_np - trt_np))
    # 计算相对误差（百分比）
    relative_error = np.mean(np.abs((pt_np - trt_np) / (pt_np + 1e-8))) * 100
    return {
        "max_abs_error": max_abs_error,
        "mean_abs_error": mean_abs_error,
        "relative_error_%": relative_error
    }

# 假设已有pt_output和trt_output
diff = calculate_accuracy_diff(pt_output, trt_output)
print(f"精度差异: {diff}")

4. 性能回归测试 (Performance Regression Testing)

监控部署模型在延迟 (Latency)、吞吐量 (Throughput) 和 资源消耗 上的变化，防止优化引入性能倒退。

  • 关键性能指标 (KPIs)：
    • 延迟：单次推理时间（毫秒，ms）。
    • 吞吐量：每秒处理的样本数（样本/秒）。
    • GPU内存：峰值显存占用（MB）。
    • CPU利用率：推理期间的平均CPU使用率（%）。
  • 测试策略：
    1. 基线测试：记录原始模型性能作为基准。
    2. 自动化脚本：每次代码提交后自动运行性能测试。
    3. 阈值报警：设置性能下降红线（如延迟增加 > 10%）。
# 示例：使用Python进行简单的性能基准测试
import time
import statistics

def benchmark_model(session, input_data, warmup=10, runs=100):
    """基准测试函数：测量模型的平均延迟和吞吐量"""
    # 预热
    for _ in range(warmup):
        _ = session.run(None, input_data)
    
    latencies = []
    for _ in range(runs):
        start = time.perf_counter()
        _ = session.run(None, input_data)
        end = time.perf_counter()
        latencies.append((end - start) * 1000)  # 转换为毫秒
    
    avg_latency = statistics.mean(latencies)
    throughput = 1000 / avg_latency  # 每秒处理样本数
    p95_latency = np.percentile(latencies, 95)
    
    return {
        "平均延迟 (ms)": round(avg_latency, 2),
        "P95延迟 (ms)": round(p95_latency, 2),
        "吞吐量 (样本/秒)": round(throughput, 1)
    }

# 使用示例
results = benchmark_model(ort_session, {"input": dummy_data})
print("性能测试结果:", results)
