📘 本章概述

在模型部署流程中，直接从训练框架导出的ONNX模型往往包含大量冗余计算、临时变量和未优化的算子结构。本章将深入讲解如何使用ONNX Simplifier等工具对模型进行优化，包括常量折叠、算子融合和冗余节点消除，从而提升模型推理效率，减少内存占用，并为后续TensorRT等推理引擎的加速做好准备。

🔧 核心优化技术

🧹

常量折叠

将计算图中在推理时可预先计算的节点替换为常量值，减少运行时计算。

⚡

算子融合

将多个细粒度算子合并为一个复合算子，减少内核启动开销和数据搬运。

✂️

冗余节点消除

删除无用的节点（如恒等变换、重复计算），简化计算图结构。

📦

模型简化

使用ONNX Simplifier自动应用上述优化，得到干净、高效的模型。

🚀 实战：使用ONNX Simplifier

1. 安装工具

# 安装 onnx-simplifier 及其依赖
pip install onnx-simplifier onnxruntime

# 验证安装
python -c "import onnxsim; print('ONNX Simplifier installed successfully!')"

2. 基本使用

import onnx
from onnxsim import simplify

# 加载原始模型
model_path = "resnet50.onnx"
original_model = onnx.load(model_path)

# 执行简化
simplified_model, check_ok = simplify(original_model)

if check_ok:
    # 保存简化后的模型
    onnx.save(simplified_model, "resnet50_simplified.onnx")
    print("模型简化成功！")
else:
    print("模型简化验证失败，请检查原始模型。")

3. 高级参数配置

# 进阶简化，启用更多优化选项
simplified_model, check_ok = simplify(
    original_model,
    skip_shape_inference=False,  # 是否跳过形状推断
    input_shapes={'input': [1, 3, 224, 224]} if dynamic_shape else None,
    perform_optimization=True,   # 执行优化
    skip_fuse_bn=True            # 是否跳过BN融合（某些场景需保留）
)

💡 最佳实践与注意事项

  • 优化顺序：先进行常量折叠，再进行算子融合，最后消除冗余节点。
  • 动态形状：如果模型包含动态维度（如batch size），需在简化时提供示例输入形状。
  • 验证结果：优化后务必使用ONNX Runtime验证模型输出与原始模型的一致性。
  • 版本兼容：确保ONNX Simplifier与ONNX IR版本匹配，避免兼容性问题。
  • 特定算子保留：某些部署后端可能需要保留特定算子结构（如QuantizeLinear），需跳过相关融合。

常见问题排查

  1. 简化后精度下降：检查是否融合了不兼容的算子，或尝试关闭某些优化选项。
  2. 简化失败：确认原始模型符合ONNX标准，尝试更新onnx和onnx-simplifier版本。
  3. 推理速度未提升：可能瓶颈不在计算图，需结合Profiler工具分析性能热点。
