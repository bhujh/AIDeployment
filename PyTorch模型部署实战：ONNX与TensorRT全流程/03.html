三、自动求导(Autograd)

PyTorch的自动微分引擎，用于神经网络训练中的反向传播。

1. 基本使用

# 创建需要梯度的张量
x = torch.tensor(2.0, requires_grad=True)
y = torch.tensor(3.0, requires_grad=True)

# 进行计算
z = x**2 + y**3 + 5

# 反向传播计算梯度
z.backward()

print(f"∂z/∂x = {x.grad}")  # 输出: 4.0 (因为 ∂z/∂x = 2x)
print(f"∂z/∂y = {y.grad}")  # 输出: 27.0 (因为 ∂z/∂y = 3y²)

2. 计算图概念

注意：训练时，需要调用zero_grad()清除累积的梯度，避免梯度累加。

四、神经网络模块构建

使用torch.nn模块构建神经网络。

1. 自定义网络层

import torch.nn as nn
import torch.nn.functional as F

class SimpleCNN(nn.Module):
    def __init__(self):
        super(SimpleCNN, self).__init__()
        # 卷积层
        self.conv1 = nn.Conv2d(3, 16, kernel_size=3, padding=1)
        self.conv2 = nn.Conv2d(16, 32, kernel_size=3, padding=1)
        # 池化层
        self.pool = nn.MaxPool2d(2, 2)
        # 全连接层
        self.fc1 = nn.Linear(32 * 8 * 8, 256)
        self.fc2 = nn.Linear(256, 10)
        # 丢弃层防止过拟合
        self.dropout = nn.Dropout(0.25)
    
    def forward(self, x):
        # 前向传播定义
        x = self.pool(F.relu(self.conv1(x)))
        x = self.pool(F.relu(self.conv2(x)))
        x = x.view(-1, 32 * 8 * 8)  # 展平
        x = F.relu(self.fc1(x))
        x = self.dropout(x)
        x = self.fc2(x)
        return x

# 实例化模型
model = SimpleCNN()
print(model)

2. 常用层类型

层类型 PyTorch类 主要参数

五、模型训练与保存

1. 训练流程

  1. 准备数据集和数据加载器
  2. 定义模型、损失函数和优化器
  3. 训练循环：前向传播、计算损失、反向传播、参数更新
  4. 验证和测试
  5. 保存和加载模型

2. 完整训练示例

import torch.optim as optim
from torch.utils.data import DataLoader, TensorDataset

# 1. 准备模拟数据
inputs = torch.randn(100, 3, 32, 32)  # 100张32x32的RGB图像
labels = torch.randint(0, 10, (100,))  # 100个标签(0-9)
dataset = TensorDataset(inputs, labels)
dataloader = DataLoader(dataset, batch_size=16, shuffle=True)

# 2. 初始化模型、损失函数、优化器
model = SimpleCNN()
criterion = nn.CrossEntropyLoss()  # 交叉熵损失
optimizer = optim.Adam(model.parameters(), lr=0.001)

# 3. 训练循环
num_epochs = 10
for epoch in range(num_epochs):
    model.train()  # 设置为训练模式
    running_loss = 0.0
    
    for batch_idx, (data, target) in enumerate(dataloader):
        # 清零梯度
        optimizer.zero_grad()
        
        # 前向传播
        outputs = model(data)
        
        # 计算损失
        loss = criterion(outputs, target)
        
        # 反向传播
        loss.backward()
        
        # 更新参数
        optimizer.step()
        
        running_loss += loss.item()
    
    # 每个epoch打印平均损失
    avg_loss = running_loss / len(dataloader)
    print(f"Epoch [{epoch+1}/{num_epochs}], Loss: {avg_loss:.4f}")

3. 模型保存与加载

# 保存整个模型
torch.save(model, 'model_complete.pth')

# 仅保存模型参数（推荐）
torch.save(model.state_dict(), 'model_weights.pth')

# 加载整个模型
loaded_model = torch.load('model_complete.pth')

# 加载模型参数
new_model = SimpleCNN()
new_model.load_state_dict(torch.load('model_weights.pth'))
new_model.eval()  # 设置为评估模式
最佳实践：通常推荐保存state_dict()而不是整个模型，因为这样更灵活且与代码结构解耦。
