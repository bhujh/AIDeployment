第13讲：动态形状支持 — 动态批次、动态维度、配置优化与运行时形状推断

📊 动态形状支持概述

在实际部署中，模型的输入尺寸往往不是固定的。动态形状支持允许模型处理可变尺寸的输入，是生产环境部署的关键能力。

  • 动态批次：批量大小在运行时可变。
  • 动态维度：如图像宽高、序列长度等维度可变。
  • 配置文件优化：针对动态范围生成优化配置。
  • 运行时形状推断：引擎根据实际输入调整内部结构。

⚙️ ONNX 动态轴设置

在导出ONNX模型时，通过 dynamic_axes 参数指定动态维度。

import torch
import torch.onnx

model = ... # 你的PyTorch模型
dummy_input = torch.randn(1, 3, 224, 224)

# 定义动态轴：批次（第0维）和图像高度/宽度（第2、3维）为动态
dynamic_axes = {
    'input': {0: 'batch_size', 2: 'height', 3: 'width'},
    'output': {0: 'batch_size'}
}

torch.onnx.export(
    model,
    dummy_input,
    "dynamic_model.onnx",
    input_names=['input'],
    output_names=['output'],
    dynamic_axes=dynamic_axes,
    opset_version=13
)
提示： ONNX opset 11+ 对动态形状支持更好。确保模型中所有操作都支持动态尺寸。

🔧 TensorRT 动态形状配置

TensorRT 使用 IOptimizationProfile 来定义每个动态输入的最小、最优、最大尺寸。

配置步骤

  1. 创建优化配置文件（Optimization Profile）。
  2. 为每个输入设置动态范围。
  3. 将配置文件添加到构建配置中。
  4. 在推理时，为每个上下文设置活动配置文件。
# Python API 示例（TensorRT）
import tensorrt as trt

builder = trt.Builder(logger)
network = builder.create_network(1 << int(trt.NetworkDefinitionCreationFlag.EXPLICIT_BATCH))
parser = trt.OnnxParser(network, logger)

# 解析ONNX模型
with open("dynamic_model.onnx", "rb") as f:
    parser.parse(f.read())

config = builder.create_builder_config()
profile = builder.create_optimization_profile()

# 设置动态输入：input_name, min_shape, optimal_shape, max_shape
profile.set_shape("input", 
                  min=(1, 3, 224, 224), 
                  opt=(8, 3, 224, 224), 
                  max=(32, 3, 512, 512))
config.add_optimization_profile(profile)

# 构建引擎
engine = builder.build_engine(network, config)
形状类型用途示例值
最小形状 (min)确定内存下限，用于最坏情况优化(1, 3, 224, 224)
最优形状 (opt)最常见的输入尺寸，用于内核优化(8, 3, 224, 224)
最大形状 (max)内存分配上限，防止溢出(32, 3, 512, 512)

📈 运行时形状推断与执行

TensorRT 引擎在运行时根据实际输入形状选择最优内核并执行。

# 运行时设置动态形状并执行
context = engine.create_execution_context()

# 设置当前输入的形状
input_shape = (4, 3, 256, 256)  # 实际输入形状
context.set_binding_shape(0, input_shape)

# 分配输入/输出缓冲区
inputs, outputs, bindings = ... # 分配GPU内存

# 执行推理
context.execute_v2(bindings=bindings)

最佳实践

  • 尽量缩小最小与最大形状的范围，以减少内存开销。
  • 最优形状应设置为最频繁出现的尺寸，以获得最佳性能。
  • 对于多输入模型，确保所有输入的动态轴设置一致。
  • 使用 context.all_binding_shapes_specified 检查形状是否已完全指定。
