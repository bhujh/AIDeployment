📚 课程概述

本课程深入讲解如何将训练好的PyTorch BERT模型部署到生产环境。重点涵盖模型转换至ONNX格式、处理可变长度输入序列（动态Shape）、以及利用TensorRT进行高性能推理优化。通过本课程，您将掌握工业级NLP模型部署的核心技能。

学习目标： 能够独立完成BERT类模型的端到端部署流水线，理解动态维度处理原理，并实现显著的推理加速。

🔄 BERT模型部署核心流程

  1. 模型准备与验证： 加载训练好的PyTorch BERT模型，确保其推理功能正常。
  2. ONNX导出： 使用torch.onnx.export将模型转换为ONNX格式，这是跨平台部署的桥梁。
  3. 动态序列处理： 配置输入输出的动态维度，以支持可变的句子长度。
  4. TensorRT引擎构建： 使用ONNX-TensorRT解析器或TRT Python API构建优化后的推理引擎。
  5. 部署与测试： 集成引擎到服务中，进行精度与性能测试。

🔧 关键技术点详解

1. PyTorch BERT模型导出为ONNX

关键步骤是创建正确的输入样例（dummy input）并指定动态维度。

import torch
from transformers import BertModel, BertTokenizer

# 1. 加载模型和分词器
model_name = 'bert-base-uncased'
model = BertModel.from_pretrained(model_name, torchscript=True)
tokenizer = BertTokenizer.from_pretrained(model_name)
model.eval()

# 2. 创建动态输入样例
# batch_size 和 seq_len 设置为动态维度
dummy_input = {
    'input_ids': torch.randint(0, 1000, (1, 128), dtype=torch.long),
    'attention_mask': torch.ones(1, 128, dtype=torch.long),
    'token_type_ids': torch.zeros(1, 128, dtype=torch.long)
}

# 3. 导出ONNX模型
input_names = ['input_ids', 'attention_mask', 'token_type_ids']
output_names = ['last_hidden_state', 'pooler_output']

dynamic_axes = {
    'input_ids': {0: 'batch_size', 1: 'seq_len'},
    'attention_mask': {0: 'batch_size', 1: 'seq_len'},
    'token_type_ids': {0: 'batch_size', 1: 'seq_len'},
    'last_hidden_state': {0: 'batch_size', 1: 'seq_len'},
    'pooler_output': {0: 'batch_size'}
}

torch.onnx.export(
    model,
    tuple(dummy_input.values()),
    'bert_dynamic.onnx',
    input_names=input_names,
    output_names=output_names,
    dynamic_axes=dynamic_axes,
    opset_version=13,
    do_constant_folding=True
)
print("ONNX模型导出成功！")

2. 动态序列长度处理策略

🔄 动态维度配置

在ONNX导出时，将序列长度（seq_len）和批处理大小（batch_size）维度标记为动态。这允许引擎在运行时接受不同尺寸的输入。

⚡ 优化Profile设置

在TensorRT中，需要为每个动态维度提供优化配置文件（Optimization Profile），定义最小、最优、最大尺寸，供引擎选择最佳内核。

3. TensorRT引擎构建代码示例

import tensorrt as trt

logger = trt.Logger(trt.Logger.INFO)
builder = trt.Builder(logger)
network = builder.create_network(1 << int(trt.NetworkDefinitionCreationFlag.EXPLICIT_BATCH))
parser = trt.OnnxParser(network, logger)

# 解析ONNX模型
with open('bert_dynamic.onnx', 'rb') as model_file:
    parser.parse(model_file.read())

# 配置优化Profile
config = builder.create_builder_config()
config.set_memory_pool_limit(trt.MemoryPoolType.WORKSPACE, 1 << 30) # 1GB

profile = builder.create_optimization_profile()
# 设置输入动态范围：最小、最优、最大尺寸
profile.set_shape('input_ids', (1, 16), (1, 128), (1, 512))
profile.set_shape('attention_mask', (1, 16), (1, 128), (1, 512))
profile.set_shape('token_type_ids', (1, 16), (1, 128), (1, 512))
config.add_optimization_profile(profile)

# 构建引擎
serialized_engine = builder.build_serialized_network(network, config)
with open('bert_dynamic.engine', 'wb') as f:
    f.write(serialized_engine)
print("TensorRT引擎构建完成！")

📊 性能对比与最佳实践

最佳实践提示：
  • Profile选择： 根据实际业务中句子长度的分布，设置合理的min/opt/max值，以获得最佳性能。
  • 精度权衡： FP16精度可大幅提升速度且精度损失很小，INT8量化需要校准集，但能进一步加速。
  • 批处理： 适当增大批处理大小（batch_size）可以显著提高GPU利用率与吞吐量。
  • 内存管理： 对于长时间运行的服务，注意管理TensorRT引擎和上下文的生命周期，避免内存泄漏。
