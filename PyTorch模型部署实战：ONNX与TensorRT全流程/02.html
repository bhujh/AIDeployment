PyTorch模型部署实战

第二讲：环境搭建 — CUDA、cuDNN、PyTorch GPU、ONNX与TensorRT

课程目标

本讲将系统性地搭建PyTorch模型部署所需的完整GPU环境。我们将从驱动开始，逐步安装CUDA工具包、cuDNN加速库、PyTorch GPU版本、ONNX生态工具，最后完成TensorRT的安装与验证。确保您拥有一个稳定、高效的深度学习部署开发环境。

环境架构总览

💡 架构说明：环境搭建遵循自底向上的依赖关系。每一层都为上层提供支持，最终通过TensorRT实现高性能推理。

第一步：CUDA与cuDNN安装

1.1 检查与准备

  • 确认GPU型号：确保您的NVIDIA GPU支持CUDA。可使用 nvidia-smi 命令查看。
  • 安装NVIDIA驱动：前往NVIDIA官网下载并安装最新版显卡驱动。
nvidia-smi

1.2 安装CUDA Toolkit

访问 NVIDIA CUDA Toolkit Archive，选择与您的PyTorch版本兼容的CUDA版本（例如CUDA 11.8）。

Linux 示例 (runfile安装): 
wget https://developer.download.nvidia.com/compute/cuda/11.8.0/local_installers/cuda_11.8.0_520.61.05_linux.run
sudo sh cuda_11.8.0_520.61.05_linux.run
安装后，将CUDA路径加入环境变量： 
echo 'export PATH=/usr/local/cuda-11.8/bin:$PATH' >> ~/.bashrc
echo 'export LD_LIBRARY_PATH=/usr/local/cuda-11.8/lib64:$LD_LIBRARY_PATH' >> ~/.bashrc
source ~/.bashrc

1.3 安装cuDNN

cuDNN是深度神经网络加速库。在NVIDIA开发者网站下载与CUDA版本对应的cuDNN包，解压并复制文件到CUDA目录。

# 解压下载的cuDNN压缩包
tar -xzvf cudnn-linux-x86_64-8.x.x.x_cuda11-archive.tar.xz
# 复制文件
sudo cp cudnn-*-archive/include/cudnn*.h /usr/local/cuda/include/
sudo cp -P cudnn-*-archive/lib/libcudnn* /usr/local/cuda/lib64/
sudo chmod a+r /usr/local/cuda/include/cudnn*.h /usr/local/cuda/lib64/libcudnn*

第二步：PyTorch GPU版本安装

强烈建议使用conda或pip安装与CUDA版本匹配的PyTorch。访问 PyTorch官网 获取精确命令。

安装方式 CUDA 11.8 安装命令 说明
Conda conda install pytorch torchvision torchaudio pytorch-cuda=11.8 -c pytorch -c nvidia 推荐，自动解决依赖
Pip pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118 速度较快

验证安装

import torch
print(f"PyTorch版本: {torch.__version__}")
print(f"CUDA是否可用: {torch.cuda.is_available()}")
print(f"CUDA版本: {torch.version.cuda}")
print(f"当前GPU设备: {torch.cuda.get_device_name(0)}")

第三步：ONNX与ONNX Runtime安装

3.1 ONNX (Open Neural Network Exchange)

ONNX是一个开放的模型格式标准，用于在不同框架间转换模型。

pip install onnx onnxscript

3.2 ONNX Runtime (ORT)

ONNX Runtime是一个高性能推理引擎，支持在多种硬件上运行ONNX模型。

# 安装GPU版本（根据CUDA版本选择）
pip install onnxruntime-gpu==1.15.1
# 或者安装CPU版本
# pip install onnxruntime

验证ONNX环境

import onnx
import onnxruntime as ort
print(f"ONNX版本: {onnx.__version__}")
print(f"ONNX Runtime版本: {ort.__version__}")
print(f"ORT可用Providers: {ort.get_available_providers()}")

第四步：TensorRT安装与验证

4.1 安装TensorRT

从 NVIDIA TensorRT下载页 获取对应CUDA版本的TensorRT。推荐使用Tar文件安装。

Linux Tar安装步骤：
  1. 解压下载的TensorRT Tar包：tar -xzvf TensorRT-8.x.x.x.Linux.x86_64-gnu.cuda-11.x.tar.gz
  2. 将TensorRT库路径加入环境变量：
export LD_LIBRARY_PATH=$LD_LIBRARY_PATH:/path/to/TensorRT-8.x.x.x/lib
# 永久生效可加入 ~/.bashrc
  • 安装Python wheel包：
    • cd /path/to/TensorRT-8.x.x.x/python
pip install tensorrt-8.x.x.x-cp3x-none-linux_x86_64.whl
  • （可选）安装附加组件，如图形化工具polygraphy：pip install polygraphy

    • 4.2 验证TensorRT

    import tensorrt as trt
print(f"TensorRT版本: {trt.__version__}")
# 创建Logger和Builder，验证基础功能
logger = trt.Logger(trt.Logger.WARNING)
builder = trt.Builder(logger)
if builder:
    print("✅ TensorRT Builder创建成功，安装基本正常。")

    4.3 完整流程验证脚本

    """
环境完整验证脚本
"""
import sys
import torch
import onnx
import onnxruntime as ort
import tensorrt as trt

def check_env():
    print("="*50)
    print("深度学习部署环境验证报告")
    print("="*50)

    # 1. PyTorch
    print("\n1. PyTorch检查:")
    print(f"   版本: {torch.__version__}")
    print(f"   CUDA可用: {torch.cuda.is_available()}")
    if torch.cuda.is_available():
        print(f"   GPU设备: {torch.cuda.get_device_name(0)}")
        print(f"   CUDA版本: {torch.version.cuda}")

    # 2. ONNX
    print("\n2. ONNX检查:")
    print(f"   ONNX版本: {onnx.__version__}")

    # 3. ONNX Runtime
    print("\n3. ONNX Runtime检查:")
    print(f"   版本: {ort.__version__}")
    providers = ort.get_available_providers()
    print(f"   可用后端: {providers}")
    if 'CUDAExecutionProvider' in providers:
        print("   ✅ ONNX Runtime GPU支持已启用。")

    # 4. TensorRT
    print("\n4. TensorRT检查:")
    print(f"   版本: {trt.__version__}")
    logger = trt.Logger(trt.Logger.WARNING)
    try:
        builder = trt.Builder(logger)
        if builder:
            print("   ✅ TensorRT 引擎创建成功。")
    except Exception as e:
        print(f"   ❌ TensorRT 检查失败: {e}")

    print("\n" + "="*50)
    print("验证完成！")

if __name__ == "__main__":
    check_env()

    常见问题与排错表

    问题现象 可能原因 解决方案
    torch.cuda.is_available() 返回 False CUDA与驱动版本不匹配；PyTorch版本与CUDA版本不兼容 检查nvidia-smi与nvcc -V版本；重新安装匹配的PyTorch版本
    导入onnxruntime时提示找不到DLL ONNX Runtime GPU版本依赖的CUDA库未在路径中 确认CUDA的bin和lib64目录已加入系统PATH和LD_LIBRARY_PATH
    TensorRT导入失败 TensorRT库路径未设置；Python wheel未安装 正确设置LD_LIBRARY_PATH；安装对应Python版本的wheel文件
    模型转换到ONNX时出错 PyTorch算子不支持；动态维度设置错误 简化模型结构；检查dynamic_axes参数；使用最新版ONNX
