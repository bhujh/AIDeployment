第二章：深度学习模型基础回顾

本章将回顾深度学习模型的核心概念，为后续的量化与压缩技术打下坚实基础。

一、模型结构与参数

深度学习模型由层（Layers）堆叠而成，每一层包含可学习的参数（Parameters），主要包括：

  • 权重（Weights）：连接神经元之间的强度值，是模型学习的核心。
  • 偏置（Biases）：为每个神经元添加的偏移量，增加模型的灵活性。

模型结构定义了数据的流动路径（计算图），而参数则通过训练数据不断调整以最小化损失函数。

关键点：模型参数量是评估模型复杂度和存储需求的重要指标。例如，一个全连接层的参数量 = (输入维度 + 1) × 输出维度。

二、前向传播与反向传播

1. 前向传播 (Forward Propagation)

数据从输入层流向输出层，逐层计算并得到预测结果。

# 简化前向传播示例 (单层感知机)
def forward_pass(x, W, b):
    z = np.dot(x, W) + b  # 线性变换
    a = 1 / (1 + np.exp(-z))  # 激活函数 (Sigmoid)
    return a

# 假设输入x为[1, 2]，权重W为[[0.5], [-0.2]]，偏置b为0.1
x = np.array([1, 2])
W = np.array([[0.5], [-0.2]])
b = 0.1
output = forward_pass(x, W, b)
print("前向传播输出:", output)

2. 反向传播 (Backward Propagation)

根据损失函数计算梯度，从输出层反向逐层更新参数（链式法则）。

# 简化反向传播示例 (均方误差损失)
def backward_pass(x, y_true, y_pred, W, b, learning_rate=0.01):
    # 计算损失对输出的梯度
    dL_dy = 2 * (y_pred - y_true)
    # 假设使用Sigmoid激活，计算激活函数的梯度
    dy_dz = y_pred * (1 - y_pred)
    # 链式法则计算梯度
    dL_dz = dL_dy * dy_dz
    dL_dW = np.dot(x.T, dL_dz)
    dL_db = np.sum(dL_dz, axis=0)
    # 参数更新
    W_new = W - learning_rate * dL_dW
    b_new = b - learning_rate * dL_db
    return W_new, b_new

三、模型评估指标

评估模型性能需要使用合适的指标，不同任务（分类、回归等）的指标不同。

任务类型 常用指标 公式 / 说明
分类任务 准确率 (Accuracy) 正确预测数 / 总样本数
精确率 (Precision) TP / (TP + FP)，关注预测为正的样本中真正为正的比例
召回率 (Recall) TP / (TP + FN)，关注实际为正的样本中被正确找出的比例
F1-Score 2 * (Precision * Recall) / (Precision + Recall)，精确率与召回率的调和平均
回归任务 均方误差 (MSE) (1/n) * Σ(ŷᵢ - yᵢ)²，预测值与真实值差值的平方的平均
平均绝对误差 (MAE) (1/n) * Σ|ŷᵢ - yᵢ|，预测值与真实值差值的绝对值的平均
通用指标 损失函数值 (Loss) 模型在训练/验证集上的总体误差，如交叉熵损失、均方误差等

注意：选择评估指标需与业务目标对齐。例如，在疾病检测中，高召回率可能比高精确率更重要。

四、常见模型架构

深度学习发展过程中涌现出多种经典模型架构，适用于不同数据类型和任务。

1. 卷积神经网络 (CNN)

核心：卷积层、池化层。擅长处理网格状数据（如图像）。

  • LeNet-5：手写数字识别的开创者。
  • AlexNet / VGG：深层CNN，推动图像识别发展。
  • ResNet：引入残差连接，解决深层网络梯度消失问题。

2. 循环神经网络 (RNN) 与 LSTM/GRU

核心：循环连接，具有记忆功能。擅长处理序列数据（如文本、时间序列）。

  • RNN：基础循环单元，存在长程依赖问题。
  • LSTM：引入门控机制，有效捕捉长距离依赖。
  • GRU：LSTM的简化版，参数更少，计算效率更高。

3. Transformer

核心：自注意力机制 (Self-Attention)，并行计算能力强。已成为NLP和CV领域的主流架构。

  • BERT / GPT：基于Transformer的预训练语言模型。
  • Vision Transformer (ViT)：将Transformer应用于图像分类。
架构 主要应用领域 核心特点
CNN 图像识别、目标检测、图像分割 局部感知、参数共享、平移不变性
RNN/LSTM 机器翻译、语音识别、时间序列预测 序列建模、具有时序记忆能力
Transformer 自然语言处理、图像生成、多模态 全局依赖建模、高度并行化

本章小结
