第7章：权重量化与激活量化

权重量化策略、激活量化挑战与解决方案、混合精度量化、逐层与逐通道量化

本章深入探讨模型量化的核心组成部分：如何对模型的权重(Weights)和激活(Activations)进行高效、低损失的数值表示转换，以实现模型压缩与加速。

一、权重量化策略

权重量化是将神经网络中全精度（通常是FP32）的权重参数转换为低精度（如INT8, INT4）表示的过程，旨在减少模型存储空间和内存带宽需求。

主要策略：

  • 对称量化：量化范围关于零点对称。公式：Q = round(W / scale)。计算简单，但可能浪费非对称分布的动态范围。
  • 非对称量化：量化范围由最小值和最大值确定。公式：Q = round((W - zero_point) / scale)。能更好地利用数值范围，精度损失更小。
  • 后训练量化(PTQ)：在模型训练完成后，利用校准数据集统计权重/激活的范围，然后进行量化。部署快速，但精度可能下降。
  • 量化感知训练(QAT)：在训练的前向传播中模拟量化效应，让模型在训练过程中“适应”低精度。精度保持更好，但需要重新训练。

权重量化与反量化流程示意图

关键点： 选择量化策略时，需权衡精度损失、计算复杂度与硬件支持。对称量化广泛用于GPU，非对称量化在移动端CPU更常见。

二、激活量化挑战与解决方案

激活量化指对网络层输出（激活值）进行量化。由于激活值动态范围大且分布随输入变化，其量化比权重量化更具挑战性。

主要挑战：

  1. 动态范围大：激活值范围可能因输入样本差异巨大，难以确定固定的量化参数。
  2. 离群值(Outliers)：少数极大值会“挤占”量化区间，导致大部分值量化分辨率不足。
  3. 分布非均匀：激活分布常为非均匀（如经过ReLU后全为正），对称量化效率低。

解决方案：

解决方案 描述 优点
校准数据集 使用代表性数据（无标签）运行模型，统计各层激活的min/max或直方图，确定scale/zero_point。 简单有效，PTQ标准流程。
移动平均统计 在训练或推理过程中，动态更新激活的统计量（如EMA），适应数据分布变化。 适应在线场景，更鲁棒。
离群值处理 裁剪(Clipping)或通道分离，将离群值限制在一定范围内，或单独处理。 显著提升量化分辨率。
激活函数融合 将ReLU等激活函数与卷积/全连接层融合，减少量化操作次数和误差累积。 提升精度与速度。 
# 示例：简单的激活校准（统计最大绝对值）
def calibrate_activation(model, calib_loader):
    max_vals = {}
    for data in calib_loader:
        output = model(data)
        for name, module in model.named_modules():
            if isinstance(module, torch.nn.ReLU):
                # 假设已注册hook来捕获输出
                act_val = module.activation_cache
                max_val = act_val.abs().max().item()
                max_vals[name] = max(max_vals.get(name, 0), max_val)
    # 计算scale (对称量化)
    scales = {name: val / 127.0 for name, val in max_vals.items()}
    return scales

三、混合精度量化

混合精度量化指对模型的不同部分采用不同的量化精度（如部分层用INT8，部分用FP16或FP32），在精度和效率间取得最佳平衡。

实施方法：

  • 敏感度分析：逐层评估量化误差对整体精度的影响，对敏感层保留高精度。
  • 硬件感知搜索：结合目标硬件（如GPU Tensor Core, NPU）的加速能力，自动搜索每层最优精度。
  • 分层策略：例如，将第一层和最后一层保持为FP32（对输入输出敏感），中间层量化为INT8。

最佳实践 使用工具（如TensorRT, AIMET, NNCF）自动进行敏感度分析并生成混合精度配置。

四、逐层与逐通道量化

这是两种不同的量化粒度，决定了量化参数（scale, zero_point）的应用范围。

量化粒度 描述 计算开销 精度 典型应用
逐层量化
(Per-Tensor)		 整个张量（一层所有通道）共享一套量化参数。 低 较低（分布差异大时损失大） 早期硬件，简单模型
逐通道量化
(Per-Channel)		 对卷积核的每个输出通道（或权重的特定维度）使用独立的量化参数。 中高 高（适应通道间分布差异） 现代AI加速器（如TPU, 高通DSP）

对比与选择：

  • 逐层量化：实现简单，硬件支持广泛，但假设张量内数据分布均匀，对于深度可分离卷积等结构误差大。
  • 逐通道量化：尤其适用于权重量化，能有效处理通道间数值范围差异大的问题（如Depthwise Convolution）。激活量化一般仍用逐层。
# PyTorch 中指定逐通道量化示例
import torch
import torch.quantization

# 准备模型
model = torch.quantization.QuantWrapper(MyModel())
model.qconfig = torch.quantization.get_default_qconfig('fbgemm') # 针对服务器端

# 对于卷积层，PyTorch默认对权重使用逐通道量化，激活使用逐层量化
model_prepared = torch.quantization.prepare(model, inplace=False)
# ... 校准 ...
model_quantized = torch.quantization.convert(model_prepared)

print(model_quantized.conv1.weight().q_per_channel)  # 应输出 True
注意： 逐通道量化需要硬件支持相应的逐通道缩放操作。在部署前务必确认目标推理引擎（如TFLite, ONNX Runtime）的支持情况。

本章总结

权重量化与激活量化是模型压缩的基石。成功的量化部署需要：

  1. 根据模型结构和数据分布，选择合适的量化策略（对称/非对称，PTQ/QAT）。
  2. 正视激活量化的挑战，采用校准、裁剪等技术稳定量化范围。
  3. 利用混合精度量化在敏感层与效率层之间取得平衡。
  4. 依据硬件能力选择量化粒度（逐层/逐通道），最大化利用计算资源。
