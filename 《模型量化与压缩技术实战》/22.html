模型量化与压缩技术实战

第二十二讲：二值化与三值化网络：XNOR-Net、DoReFa-Net、TWN、极端量化下的训练技巧与精度恢复

一、概述：极致的模型压缩

在边缘计算和移动设备上部署深度学习模型时，模型大小、计算开销和内存带宽是核心瓶颈。二值化（Binary）与三值化（Ternary）网络将权重和/或激活值量化到极少的离散值（如{-1, +1} 或 {-1, 0, +1}），从而实现：

  • 极高的压缩率：权重存储减少32倍（相比FP32）。
  • 极快的推理速度：用位运算（XNOR, Popcount）替代浮点乘加。
  • 极低的功耗：减少内存访问和复杂计算。

本讲将深入剖析三种代表性网络：XNOR-Net、DoReFa-Net、TWN，并探讨极端量化下的训练技巧与精度恢复策略。

二、核心算法详解

1. XNOR-Net: 二值化权重与激活

XNOR-Net 由 Rastegari 等人提出，核心思想是将卷积运算近似为二值运算。

图1: XNOR-Net 权重二值化流程

关键公式：

卷积近似： I * W ≈ (sign(I) ⊙ sign(W)) * α * β
其中：
    sign(x) = +1 if x ≥ 0, else -1
    α = mean(|W|)  (权重缩放因子)
    β = mean(|I|)  (激活缩放因子，按通道计算)
核心操作： XNOR + bitcount 替代浮点乘加

2. DoReFa-Net: 低比特权重、激活与梯度

DoReFa-Net 将量化扩展到前向的权重、激活以及反向传播的梯度，实现端到端的低比特训练。

量化对象比特数量化函数特点
权重1-bit (二值) 或 2-bittanh(·) + 线性量化约束在[-1,1]
激活2-bit 或 4-bit量化到 [0, 1]使用分段常数函数
梯度6-bit 或 8-bit随机量化保持无偏估计

3. TWN (Ternary Weight Networks): 三值化权重

TWN 将权重约束为三个值：{-α, 0, +α}，在二值化的基础上增加了零值，提供了更好的表达能力。

# 三值化核心代码 (PyTorch 风格)
def ternary_weight(W, delta=0.7):
    # delta: 缩放比例阈值，控制稀疏度
    alpha = torch.mean(torch.abs(W))
    threshold = delta * alpha
    mask_neg = (W < -threshold).float()
    mask_pos = (W > threshold).float()
    W_ternary = mask_pos * alpha + mask_neg * (-alpha)
    # 直通估计器 (STE) 用于梯度回传
    return W_ternary + (W - W).detach()  # 保持梯度流

三、算法对比

XNOR-Net

  • 量化对象: 权重(二值)、激活(二值)
  • 核心创新: XNOR-Popcount 加速
  • 优点: 速度极快，压缩率高
  • 挑战: 精度损失较大

DoReFa-Net

  • 量化对象: 权/激/梯 (多比特)
  • 核心创新: 梯度量化，端到端训练
  • 优点: 灵活，支持不同比特配置
  • 挑战: 梯度量化噪声

TWN

  • 量化对象: 权重(三值)
  • 核心创新: 引入零值，增加稀疏性
  • 优点: 精度优于二值，仍有加速
  • 挑战: 需要阈值调参

四、极端量化下的训练技巧与精度恢复

直接进行极端量化会导致严重的精度下降。以下技巧至关重要：

1. 训练技巧

  • 预训练与微调: 先在FP32上预训练，再加载权重进行量化微调。
  • 渐进式量化: 从高比特（如8-bit）开始，逐步降低到1/2-bit。
  • 直通估计器 (STE): 在反向传播时绕过不可微的量化函数。 
    # STE 示例
class SignSTE(torch.autograd.Function):
    @staticmethod
    def forward(ctx, x):
        return torch.sign(x)
    @staticmethod
    def backward(ctx, grad_output):
        # 直接传递梯度，或使用梯度裁剪/近似
        return grad_output.clamp(-1, 1)
  • 学习缩放因子: 将缩放因子α设为可学习参数，而非简单计算均值。
  • 权重归一化: 量化前对权重进行归一化（如L1、L2范数），稳定训练。

2. 精度恢复策略

  1. 知识蒸馏 (KD): 使用全精度教师网络指导二值化学生网络训练。
  2. 激活分布调整: 在激活函数前加入可学习的偏移（bias）或缩放（scale），适配二值化。
  3. 结构优化:
    • 加宽第一层和最后一层（保持较高精度）。
    • 使用 shortcut 结构（如ResNet）缓解梯度消失。
  4. 精细调参: 使用更小的学习率、更长的训练周期、特定的优化器（如Adam）。
实战提示： 对于首次尝试，建议从 TWN 或 DoReFa-Net (2-bit) 开始，它们比纯二值网络更容易获得可接受的精度。同时，务必在验证集上监控精度变化，并耐心调整超参数。

五、总结与展望

二值化与三值化网络代表了模型压缩的极端追求。它们在特定场景（如资源极度受限的嵌入式设备）下具有不可替代的价值。然而，其精度与效率的权衡仍是核心挑战。

未来的研究方向可能包括：

  • 更智能的混合精度量化（不同层使用不同比特）。
  • 硬件友好的稀疏二值化模式设计。
  • 结合神经架构搜索（NAS）自动寻找适合量化的网络结构。
  • 探索二值化在Transformer等新兴架构上的应用。

掌握这些极端量化技术，将使你能够将强大的深度学习模型部署到任何角落，真正实现AI的普惠与落地。
