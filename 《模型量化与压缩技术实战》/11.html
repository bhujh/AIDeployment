非结构化剪枝与稀疏化

一、核心概念

非结构化剪枝是一种细粒度的模型压缩技术，它通过移除神经网络中不重要的权重（置为零），而不考虑权重在矩阵中的位置结构，从而生成高度稀疏的模型。与结构化剪枝不同，它不要求保持规整的矩阵形状，因此能获得更高的压缩率，但需要专门的硬件或软件支持来加速稀疏计算。

非结构化剪枝

  • 粒度：权重级（细粒度）
  • 规则：无结构约束
  • 压缩率：高
  • 硬件要求：需要稀疏加速支持
  • 典型应用：通用模型压缩

结构化剪枝

  • 粒度：通道/层级（粗粒度）
  • 规则：保持规整结构
  • 压缩率：中等
  • 硬件要求：通用硬件即可
  • 典型应用：移动端部署

二、权重稀疏化与掩码技术

2.1 权重重要性评估

决定哪些权重可以被置零是关键步骤。常用的重要性准则包括：

准则 计算公式/描述 优点 缺点
绝对值大小 I(w) = |w| 简单高效，最常用 忽略权重间的相关性
梯度信息 I(w) = |w · ∇wL| 结合前向与反向传播 计算开销大
Hessian敏感度 I(w) = w² · H 理论最优，精度损失小 计算Hessian矩阵极其昂贵
活动度 基于激活值的统计量 反映特征重要性 需要推理数据

2.2 掩码生成与更新策略

掩码（Mask）是一个与权重矩阵形状相同的二进制矩阵，用于指示哪些权重被保留（1）或剪枝（0）。

import torch
import numpy as np

def generate_mask(weight, sparsity_ratio=0.5, criterion='magnitude'):
    """
    生成剪枝掩码
    Args:
        weight: 权重张量
        sparsity_ratio: 目标稀疏率（0-1）
        criterion: 重要性准则
    Returns:
        mask: 二进制掩码（1保留，0剪枝）
    """
    if criterion == 'magnitude':
        # 基于绝对值大小
        threshold = torch.quantile(torch.abs(weight).float(), sparsity_ratio)
        mask = (torch.abs(weight) > threshold).float()
    elif criterion == 'random':
        # 随机剪枝（基线方法）
        mask = torch.rand_like(weight) > sparsity_ratio
        mask = mask.float()
    else:
        raise ValueError(f"Unsupported criterion: {criterion}")
    return mask

# 示例：对线性层权重进行剪枝
linear_weight = torch.randn(128, 256) * 0.1
mask = generate_mask(linear_weight, sparsity_ratio=0.7)
pruned_weight = linear_weight * mask  # 应用掩码
print(f"原始参数量: {linear_weight.numel()}")
print(f"稀疏后参数量: {torch.sum(mask).item()}")
print(f"实际稀疏率: {1 - torch.sum(mask).item() / mask.numel():.3f}")
掩码更新策略： 常见的更新策略包括一次性剪枝（One-shot）、迭代剪枝（Iterative）和动态剪枝（Dynamic）。迭代剪枝通常能获得更好的精度，其过程为：训练 → 剪枝最不重要的权重 → 微调 → 重复，直到达到目标稀疏率。

三、稀疏矩阵存储与计算优化

3.1 稀疏存储格式

为了高效存储稀疏矩阵，避免存储大量零值，业界提出了多种存储格式：

  • COO（Coordinate Format）： 存储非零元素的行索引、列索引和值。适合通用操作，但存储开销相对较大。
  • CSR（Compressed Sparse Row）： 压缩行格式，存储行指针、列索引和值。适合行操作多的场景。
  • CSC（Compressed Sparse Column）： 压缩列格式，存储列指针、行索引和值。适合列操作多的场景。
  • Block Sparse： 将矩阵分块，只存储非零块。能更好地利用局部性，适合GPU计算。

3.2 稀疏计算优化

稀疏矩阵乘法（SpMM）和卷积是神经网络中的核心操作。优化方法包括：

  1. 专用内核： 编写CUDA/OpenCL内核，直接操作稀疏格式数据，避免零值计算。
  2. 负载均衡： 由于非零元素分布不均，需要动态调度线程以避免空闲。
  3. 内存访问优化： 利用共享内存、缓存预取等技术减少内存带宽压力。
  4. 库支持： 使用cuSPARSE（NVIDIA）、MKL（Intel）、Eigen等优化库。

四、稀疏训练技巧

直接在稀疏模型上进行训练（从头开始训练稀疏网络）比先训练后剪枝更具挑战性，但能获得更好的最终性能。

4.1 动态稀疏训练

在训练过程中允许权重在零与非零之间动态变化：

class DynamicSparseTraining:
    def __init__(self, model, sparsity=0.8, update_freq=100):
        self.model = model
        self.sparsity = sparsity
        self.update_freq = update_freq
        self.step = 0
        self.masks = {}
        
    def apply_masks(self):
        """为所有参数应用掩码"""
        for name, param in self.model.named_parameters():
            if 'weight' in name and param.dim() >= 2:
                if name not in self.masks:
                    self.masks[name] = torch.ones_like(param)
                param.data *= self.masks[name]
    
    def update_masks(self):
        """定期更新掩码：剪枝不重要的权重，激活新的权重"""
        if self.step % self.update_freq != 0:
            return
            
        for name, param in self.model.named_parameters():
            if 'weight' in name and param.dim() >= 2:
                # 1. 计算重要性（绝对值）
                importance = torch.abs(param.data)
                
                # 2. 确定阈值
                num_params = param.numel()
                num_prune = int(self.sparsity * num_params)
                if num_prune == 0:
                    continue
                    
                # 3. 找到最不重要的权重进行剪枝
                threshold = torch.kthvalue(importance.flatten(), num_prune).values
                prune_mask = (importance <= threshold)
                
                # 4. 随机激活相同数量的新权重
                num_activate = prune_mask.sum().item()
                activate_candidates = (self.masks[name] == 0)  # 当前为零的位置
                if activate_candidates.sum() > 0:
                    prob = activate_candidates.float()
                    prob = prob / prob.sum()
                    activate_idx = torch.multinomial(prob, num_activate)
                    new_mask = torch.zeros_like(param)
                    new_mask.flatten()[activate_idx] = 1
                
                # 5. 更新掩码
                self.masks[name] = (~prune_mask).float()
                self.masks[name] += new_mask
                self.masks[name] = (self.masks[name] > 0).float()
                
                # 6. 应用新掩码并重置新权重
                param.data *= self.masks[name]
                param.data += torch.randn_like(param) * 0.01 * new_mask  # 小随机初始化新权重

4.2 实用技巧与最佳实践

技巧 描述 效果
渐进式稀疏化 从低稀疏率开始，逐步增加至目标稀疏率 稳定训练，精度更高
梯度重定向 将被剪枝权重的梯度加到保留权重上 减少信息损失，加速收敛
学习率预热 在稀疏训练初期使用较低学习率 避免梯度爆炸，稳定训练
正则化调整 减少L2正则化强度，避免过度惩罚大权重 保持模型容量
结构化稀疏诱导 在非结构化剪枝中加入轻微的结构化约束 平衡压缩率与硬件效率
重要提示： 非结构化剪枝的实际加速效果高度依赖于硬件和软件栈的支持。在支持稀疏计算的专用硬件（如NVIDIA A100的稀疏张量核心）上，最高可实现2倍的推理加速。在通用GPU上，通常需要稀疏率超过90%才能获得明显加速。

五、总结与展望

非结构化剪枝与稀疏化是模型压缩领域的重要技术，能够在不显著损失精度的情况下大幅减少模型参数量和计算量。其核心流程包括：

  1. 权重重要性评估：选择合适的准则识别不重要的权重。
  2. 掩码生成与更新：通过一次性或迭代方式生成稀疏模式。
  3. 稀疏存储与计算：采用高效格式存储，并利用优化库进行计算。
  4. 稀疏训练与微调：在稀疏约束下重新训练或微调模型以恢复精度。

未来发展方向包括：自动化稀疏率分配、硬件感知的稀疏模式学习、动态稀疏推理、以及与其他压缩技术（如量化、知识蒸馏）的联合优化。
