知识蒸馏实战

使用PyTorch实现分类模型蒸馏、温度调节、学生网络设计与效果评估

《模型量化与压缩技术实战》第13课

一、知识蒸馏核心概念

知识蒸馏（Knowledge Distillation）是一种模型压缩技术，旨在将大型、复杂的教师模型（Teacher Model）的知识迁移到小型、高效的学生模型（Student Model）中。其核心思想是让学生模型不仅学习真实标签（硬标签），还学习教师模型输出的概率分布（软标签），从而获得更好的泛化能力。

关键优势： 学生模型在保持较小规模的同时，能够逼近甚至超越教师模型的性能，实现模型效率与精度的平衡。

二、PyTorch实现分类模型蒸馏

2.1 整体流程

  1. 准备阶段： 加载预训练教师模型、定义学生模型、准备数据集。
  2. 蒸馏循环： 前向传播获取教师和学生的输出，计算蒸馏损失和分类损失，反向传播更新学生网络。
  3. 评估阶段： 在测试集上评估学生模型的性能。

2.2 核心代码实现

import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import models, datasets, transforms

# 1. 定义蒸馏损失函数 (KL散度 + 交叉熵)
class DistillationLoss(nn.Module):
    def __init__(self, temperature=4.0, alpha=0.7):
        super().__init__()
        self.temperature = temperature
        self.alpha = alpha
        self.kl_loss = nn.KLDivLoss(reduction='batchmean')
        self.ce_loss = nn.CrossEntropyLoss()

    def forward(self, student_logits, teacher_logits, labels):
        # 软标签损失 (KL散度)
        soft_loss = self.kl_loss(
            nn.functional.log_softmax(student_logits / self.temperature, dim=1),
            nn.functional.softmax(teacher_logits / self.temperature, dim=1)
        ) * (self.temperature ** 2) * self.alpha

        # 硬标签损失 (交叉熵)
        hard_loss = self.ce_loss(student_logits, labels) * (1 - self.alpha)

        return soft_loss + hard_loss

# 2. 训练循环中的蒸馏步骤
def train_epoch_distill(student, teacher, train_loader, criterion, optimizer, device, temperature):
    student.train()
    teacher.eval()
    running_loss = 0.0

    for inputs, labels in train_loader:
        inputs, labels = inputs.to(device), labels.to(device)

        with torch.no_grad():
            teacher_logits = teacher(inputs)  # 教师前向传播

        student_logits = student(inputs)      # 学生前向传播

        # 计算蒸馏损失
        loss = criterion(student_logits, teacher_logits, labels)

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

        running_loss += loss.item() * inputs.size(0)

    return running_loss / len(train_loader.dataset)

三、蒸馏温度调节

温度参数（Temperature, T）是知识蒸馏中的超参数，用于控制软标签的“软化”程度。

温度的影响：

  • T = 1： 输出为标准Softmax，概率分布尖锐。
  • T > 1： 概率分布更平滑，蕴含更多类别间关系信息（暗知识）。
  • T 非常大： 分布接近均匀分布，信息量减少。

调节策略：

  • 常用范围： 3.0 ~ 10.0。
  • 初始尝试： 从 T=4.0 开始。
  • 动态调整： 可随训练轮次衰减。

四、学生网络设计策略

设计维度 策略选项 说明与建议
网络结构 更浅、更窄的网络 如减少卷积层数、通道数，使用MobileNet、ShuffleNet等轻量架构
与教师相似性 同构 vs 异构 同构设计（如都是CNN）更易蒸馏；异构（如教师CNN，学生MLP）更具挑战
中间层监督 特征图匹配 让学生中间层特征逼近教师对应层，引入额外损失（如MSE）
注意力转移 注意力图蒸馏 迁移教师模型的注意力区域，提升学生特征提取能力
多教师蒸馏 集成多个教师 融合多个教师模型的软标签，为学生提供更丰富的监督信号
实战建议： 对于图像分类任务，可选用 ResNet18 作为教师，MobileNetV2 或自定义的小型CNN作为学生。优先保证学生网络有足够的容量学习教师知识，再考虑压缩极限。

五、蒸馏效果评估

5.1 评估指标

  • Top-1 / Top-5 准确率： 在测试集上的分类精度。
  • 模型大小（参数量）： 学生 vs 教师的参数对比。
  • 推理速度（FPS）： 在目标硬件上的每秒处理帧数。
  • 损失曲线： 训练过程中蒸馏损失与验证损失的变化。

5.2 对比实验设计

  • 基准模型： 学生网络单独训练（无蒸馏）。
  • 蒸馏模型： 使用教师知识蒸馏后的学生网络。
  • 教师模型： 作为性能上限参考。
# 评估脚本示例
def evaluate_model(model, test_loader, device):
    model.eval()
    correct = 0
    total = 0
    with torch.no_grad():
        for inputs, labels in test_loader:
            inputs, labels = inputs.to(device), labels.to(device)
            outputs = model(inputs)
            _, predicted = torch.max(outputs.data, 1)
            total += labels.size(0)
            correct += (predicted == labels).sum().item()
    accuracy = 100 * correct / total
    return accuracy

# 计算参数量
def count_parameters(model):
    return sum(p.numel() for p in model.parameters() if p.requires_grad)

print(f"教师参数量: {count_parameters(teacher_model):,}")
print(f"学生参数量: {count_parameters(student_model):,}")
print(f"教师准确率: {evaluate_model(teacher_model, test_loader, device):.2f}%")
print(f"学生蒸馏准确率: {evaluate_model(student_model, test_loader, device):.2f}%")

六、总结与最佳实践

  • 温度选择： 从T=4开始实验，根据任务复杂度调整。过高的温度可能导致信息模糊。
  • 损失权重α： 平衡软标签与硬标签的重要性，通常设置在0.5~0.9之间。
  • 渐进式蒸馏： 可先使用高温度训练，后期逐渐降低温度，聚焦于困难样本。
  • 中间层监督： 对于深层网络，引入中间特征匹配损失能显著提升效果。
  • 数据增强： 蒸馏过程中使用与教师训练时相同或更强的数据增强。
  • 验证集监控： 密切监控学生模型在验证集上的表现，防止过拟合教师噪声。

知识蒸馏是模型压缩与加速的强大工具，通过巧妙的知识迁移，能够在资源受限的环境中部署高性能模型。
