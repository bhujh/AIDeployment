自然语言处理模型压缩实战

第26课：BERT等预训练模型压缩、词嵌入量化、注意力机制剪枝、蒸馏TinyBERT实战

课程概述

随着BERT、GPT等大规模预训练模型在自然语言处理任务中取得突破性进展，其庞大的参数量与计算需求成为实际部署的主要障碍。本课程深入探讨NLP模型压缩的核心技术，旨在将大模型“瘦身”为高效、轻量且保持高性能的实用模型。

学习目标：掌握BERT等预训练模型的四大压缩技术：量化、剪枝、知识蒸馏与参数共享，并能够通过TinyBERT实战项目完成从理论到实践的转化。

核心技术概览

预训练模型压缩

针对BERT、RoBERTa等模型，通过结构化剪枝、层丢弃等方法减少模型深度与宽度，显著降低计算开销。

词嵌入量化

将浮点型词向量（如FP32）转换为低精度表示（如INT8），减少存储与内存带宽，加速推理。

注意力机制剪枝

识别并移除注意力头中的冗余连接，保留关键语义信息，提升自注意力层的计算效率。

知识蒸馏 (TinyBERT)

将大型“教师模型”的知识迁移至小型“学生模型”，在保持性能的同时大幅压缩模型规模。

关键技术详解

1. 预训练模型压缩方法对比

方法 原理 压缩率 性能保持 适用场景
权重剪枝 移除绝对值较小的权重（稀疏化） 50%-90% 中等 存储受限，推理延迟要求高
层剪枝 删除整个Transformer层或注意力头 30%-70% 中高 计算资源有限，需要减少层数
量化 降低权重/激活值精度（FP32→INT8） 75% (存储) 高 移动端、嵌入式部署
知识蒸馏 大模型指导小模型训练 90%+ (参数量) 高 需要轻量模型且保持精度

2. 词嵌入量化实战示例

词嵌入层通常占据模型总参数的相当大部分。通过量化，可将FP32浮点向量转换为INT8整数表示，显著减少内存占用。

import torch
import torch.nn as nn
from torch.quantization import quantize_dynamic

# 假设有一个预训练的BERT模型
class BERTEmbedding(nn.Module):
    def __init__(self, vocab_size=30522, hidden_size=768):
        super().__init__()
        self.word_embeddings = nn.Embedding(vocab_size, hidden_size)
        self.position_embeddings = nn.Embedding(512, hidden_size)
        self.token_type_embeddings = nn.Embedding(2, hidden_size)
        
    def forward(self, input_ids, token_type_ids=None, position_ids=None):
        # 前向传播逻辑
        pass

# 动态量化词嵌入层
model = BERTEmbedding()
quantized_model = quantize_dynamic(
    model,
    {nn.Embedding},  # 指定要量化的模块类型
    dtype=torch.qint8
)

print("原始嵌入层大小:", sum(p.numel() for p in model.parameters()))
print("量化后嵌入层大小:", sum(p.numel() for p in quantized_model.parameters()))
# 注意：实际存储大小会减少约75%

3. 注意力机制剪枝策略

  • 头重要性评估：基于注意力权重熵、梯度信息或对下游任务的影响评分。
  • 结构化剪枝：移除整个注意力头，保持矩阵运算的规整性。
  • 渐进式剪枝：迭代式移除最不重要的头，每轮微调以恢复性能。
  • 跨层共享：不同层共享相同的注意力头参数，减少冗余。

4. TinyBERT蒸馏实战核心步骤

  1. 通用蒸馏：在大量文本数据上，将教师模型（BERT-base）的嵌入层、注意力矩阵、隐藏状态知识蒸馏到学生模型（TinyBERT）。
  2. 任务特定蒸馏：在特定下游任务（如GLUE）数据上进一步蒸馏，提升任务性能。
  3. 数据增强：使用词替换、删除等技巧扩充训练数据，提升学生模型的泛化能力。
  4. 联合优化：结合注意力损失、隐藏状态损失与预测损失进行多目标训练。
# TinyBERT蒸馏损失函数示例 (简化版)
import torch.nn.functional as F

def distillation_loss(student_logits, teacher_logits,
                     student_hidden, teacher_hidden,
                     student_attention, teacher_attention,
                     labels, alpha=0.5, temperature=3.0):
    
    # 1. 预测蒸馏损失 (软标签)
    soft_loss = F.kl_div(
        F.log_softmax(student_logits / temperature, dim=-1),
        F.softmax(teacher_logits / temperature, dim=-1),
        reduction='batchmean'
    ) * (temperature ** 2)
    
    # 2. 隐藏状态MSE损失
    hidden_loss = F.mse_loss(student_hidden, teacher_hidden)
    
    # 3. 注意力矩阵MSE损失
    attn_loss = F.mse_loss(student_attention, teacher_attention)
    
    # 4. 任务真实标签的交叉熵损失
    hard_loss = F.cross_entropy(student_logits, labels)
    
    # 总损失 = 软标签损失 + 隐藏损失 + 注意力损失 + 硬标签损失
    total_loss = alpha * soft_loss + 0.3 * hidden_loss + 0.2 * attn_loss + (1-alpha) * hard_loss
    return total_loss

实战建议与最佳实践

  • 组合使用：单一压缩技术效果有限，建议组合量化+剪枝+蒸馏以获得最佳效果。
  • 渐进式压缩：不要一次性过度压缩，采用渐进式策略，每步压缩后微调恢复性能。
  • 硬件感知：针对目标部署硬件（CPU、GPU、NPU）选择最合适的压缩方案。
  • 评估全面：除了准确率，还要评估推理延迟、内存占用、能耗等实际部署指标。
  • 开源工具：利用Hugging Face Transformers、PyTorch Quantization、NNI等工具加速开发。
