量化基本概念、均匀量化与非均匀量化、对称量化与非对称量化、量化误差分析

一、量化基本概念

模型量化是一种将深度学习模型中高精度数值（如32位浮点数）转换为低精度数值（如8位整数）的技术，旨在减少模型存储空间、加速推理计算并降低功耗，同时尽可能保持模型精度。

核心目标：在精度损失与效率提升之间取得最佳平衡。

  • 量化优势：减小模型体积、降低内存带宽、加速计算、降低能耗。
  • 量化对象：权重（Weights）、激活值（Activations）、梯度（Gradients）。
  • 量化粒度：逐层量化、逐通道量化、逐组量化。

二、均匀量化与非均匀量化

1. 均匀量化（Uniform Quantization）

将浮点数值域均匀地映射到整数域，量化步长（scale）固定。是最常用、硬件友好的量化方式。

量化公式：

Q = round(R / S) + Z
R ≈ S * (Q - Z)

其中，R为实数值，Q为量化整数值，S为缩放因子（scale），Z为零点（zero-point）。

2. 非均匀量化（Non-uniform Quantization）

根据数值分布特点，使用非均匀的间隔进行映射，对重要区域（如零点附近）使用更密集的量化级别。

量化类型 映射方式 优点 缺点 典型应用
均匀量化 等间隔划分 计算简单，硬件支持好 对非均匀分布数据效率低 CNN权重、激活值
非均匀量化 不等间隔划分（如对数、幂律） 对特定分布数据精度更高 计算复杂，硬件支持有限 语音信号、特定分布激活

三、对称量化与非对称量化

1. 对称量化（Symmetric Quantization）

量化范围关于零点对称，即 [-α, α]。零点 Z=0，无需存储零点偏移，计算更简单。

# 对称量化示例 (TensorRT风格)
scale = max(abs(min_val), abs(max_val)) / (2^(b-1)-1)
quantized_value = round(float_value / scale)

2. 非对称量化（Asymmetric Quantization）

量化范围不对称，即 [β, α]。引入零点 Z 来精确表示真实零点，能更好地利用量化范围。

# 非对称量化示例 (TensorFlow Lite风格)
scale = (max_val - min_val) / (2^b - 1)
zero_point = round(-min_val / scale)
quantized_value = round(float_value / scale) + zero_point
特性 对称量化 非对称量化
量化范围 [-α, α] [β, α]
零点 (Z) 0（固定） 可调（通常非零）
计算复杂度 低 稍高
范围利用率 可能浪费一半范围 充分利用整个范围
适用场景 权重（分布对称） 激活值（ReLU后非负）

实践建议：权重通常使用对称量化，激活值（尤其是ReLU后）使用非对称量化以获得更好的精度。

四、量化误差分析

量化误差是量化过程中引入的信息损失，主要来源于舍入误差和截断误差。

误差度量指标

  • 均方误差 (MSE)： MSE = 1/n Σ(Q_i - R_i)²
  • 信噪比 (SNR)： SNR = 10·log10(信号功率 / 噪声功率)
  • 余弦相似度： 衡量量化前后向量方向的一致性。

减少量化误差的技术

  1. 校准（Calibration）： 使用代表性数据集确定最佳量化参数（scale, zero_point）。
  2. 量化感知训练（QAT）： 在训练前向传播中模拟量化误差，让模型适应低精度表示。
  3. 混合精度量化： 对敏感层保留较高精度（如FP16），其他层使用低精度（如INT8）。
  4. 后训练量化（PTQ）： 训练后调整量化参数，无需重新训练。

关键洞察： 量化误差并非均匀分布。对于深度模型，误差会逐层累积，因此需要仔细分析每层的敏感度，并可能采用分层量化策略。

五、总结与最佳实践

模型量化是部署高效深度学习模型的关键技术。理解均匀/非均匀、对称/非对称量化的原理及其误差特性，是成功实施量化的基础。

  • 起步建议： 从后训练均匀量化（对称用于权重，非对称用于激活）开始。
  • 精度提升： 若精度下降过多，采用量化感知训练（QAT）。
  • 硬件适配： 量化方案需考虑目标硬件（CPU/GPU/NPU）的支持特性。
  • 评估必须： 量化后必须在验证集上全面评估精度、速度和大小。
