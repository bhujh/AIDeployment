TensorRT模型优化与部署实战

第16讲：TensorRT简介、ONNX模型转换、Builder配置与推理引擎构建

一、TensorRT简介

NVIDIA TensorRT 是一个高性能的深度学习推理（Inference）优化器和运行时库。它旨在将训练好的神经网络模型进行优化，并在NVIDIA GPU上提供低延迟、高吞吐量的推理服务。

核心特性

  • 层融合（Layer Fusion）：将多个层合并为一个内核，减少内存访问和内核启动开销。
  • 精度校准（Precision Calibration）：支持FP32、FP16、INT8精度，在精度损失最小的情况下大幅提升性能。
  • 内核自动调优（Kernel Auto-Tuning）：为目标GPU选择最佳的内核实现。
  • 动态张量内存（Dynamic Tensor Memory）：高效管理内存，最小化内存占用并复用内存。
  • 多流执行（Multi-Stream Execution）：可并行处理多个输入流。
注意： TensorRT是一个推理优化器，不用于模型训练。它接收来自PyTorch、TensorFlow等框架的训练好的模型。

二、ONNX模型转换

ONNX（Open Neural Network Exchange）是一种开放的模型表示格式，是连接训练框架与推理引擎的桥梁。将模型转换为ONNX是使用TensorRT的常见第一步。

转换流程

  1. 从训练框架导出：使用PyTorch的torch.onnx.export或TensorFlow的tf2onnx工具将模型转换为ONNX格式。
  2. 简化与优化：使用ONNX Simplifier等工具对模型图进行简化。
  3. 验证：使用ONNX Runtime验证模型正确性。

PyTorch模型导出示例

import torch
import torch.onnx

# 1. 加载训练好的模型
model = YourModelClass()
model.load_state_dict(torch.load('model.pth'))
model.eval()

# 2. 创建示例输入张量
dummy_input = torch.randn(1, 3, 224, 224, device='cuda')

# 3. 导出ONNX模型
input_names = ['input']
output_names = ['output']
torch.onnx.export(model,
                  dummy_input,
                  "model.onnx",
                  verbose=True,
                  input_names=input_names,
                  output_names=output_names,
                  opset_version=11,
                  do_constant_folding=True,
                  dynamic_axes={'input': {0: 'batch_size'},
                                'output': {0: 'batch_size'}})

print("ONNX模型导出成功！")
工具/库 作用 备注
torch.onnx.export PyTorch官方导出工具 需指定opset版本
onnx-simplifier 简化ONNX模型结构 减少冗余节点
onnxruntime 验证ONNX模型推理 确保转换正确性
polygraphy TensorRT工具集的一部分 用于调试和验证

三、TensorRT Builder配置

Builder 是TensorRT的核心组件，负责从网络定义创建优化后的推理引擎。配置Builder是性能调优的关键步骤。

关键配置选项

  • 工作空间大小（Workspace Size）：分配给Builder用于优化过程的内存。
  • 精度模式（Precision Mode）：设置FP16或INT8推理，需搭配校准器（Calibrator）。
  • 层数限制（Layer Number Limit）：可设置网络层数的上限。
  • 配置文件（Profile）：用于动态形状输入，定义最小、最优、最大输入尺寸。

Builder配置代码示例

import tensorrt as trt

logger = trt.Logger(trt.Logger.WARNING)
builder = trt.Builder(logger)
network = builder.create_network(1 << int(trt.NetworkDefinitionCreationFlag.EXPLICIT_BATCH))
parser = trt.OnnxParser(network, logger)

# 解析ONNX模型
with open("model.onnx", "rb") as f:
    parser.parse(f.read())

config = builder.create_builder_config()
# 设置最大工作空间为1GB
config.max_workspace_size = 1 << 30  # 1GB
# 启用FP16精度模式
config.set_flag(trt.BuilderFlag.FP16)
# 设置优化级别
builder_config.builder_optimization_level = 3

# 对于动态形状，需要添加优化配置文件
profile = builder.create_optimization_profile()
profile.set_shape("input", min=(1,3,224,224),
                         opt=(8,3,224,224),
                         max=(32,3,224,224))
config.add_optimization_profile(profile)

print("Builder配置完成。")

四、推理引擎构建与测试

配置完成后，Builder将构建一个高度优化的推理引擎（Inference Engine）。该引擎可序列化保存（.plan或.engine文件）并在部署时高效加载。

构建与序列化引擎

# 构建引擎
engine = builder.build_engine(network, config)
if engine is None:
    print("引擎构建失败！")
    exit()

# 序列化引擎并保存
serialized_engine = engine.serialize()
with open("model.engine", "wb") as f:
    f.write(serialized_engine)
print("引擎已保存为 model.engine")

# 清理资源
del parser, network, config, builder

加载引擎并进行推理

import numpy as np
import tensorrt as trt

# 1. 加载序列化引擎
logger = trt.Logger(trt.Logger.WARNING)
runtime = trt.Runtime(logger)
with open("model.engine", "rb") as f:
    serialized_engine = f.read()
engine = runtime.deserialize_cuda_engine(serialized_engine)

# 2. 创建执行上下文
context = engine.create_execution_context()

# 3. 准备输入输出缓冲区（GPU内存）
input_name = engine.get_binding_name(0)
output_name = engine.get_binding_name(1)

# 获取输入输出尺寸
input_shape = engine.get_binding_shape(0)  # 例如 (1,3,224,224)
output_shape = engine.get_binding_shape(1)

# 分配GPU内存
import pycuda.driver as cuda
import pycuda.autoinit

d_input = cuda.mem_alloc(np.prod(input_shape) * np.dtype(np.float32).itemsize)
d_output = cuda.mem_alloc(np.prod(output_shape) * np.dtype(np.float32).itemsize)
bindings = [int(d_input), int(d_output)]

# 4. 执行推理
# 准备输入数据（假设host_input是numpy数组）
host_input = np.random.random(input_shape).astype(np.float32)
host_output = np.empty(output_shape, dtype=np.float32)

# 拷贝数据到GPU
cuda.memcpy_htod(d_input, host_input)
# 执行推理
context.execute_v2(bindings=bindings)
# 拷贝结果回CPU
cuda.memcpy_dtoh(host_output, d_output)

print("推理完成！输出形状：", host_output.shape)
print("前5个输出值：", host_output.flatten()[:5])

性能测试要点

测试项目 方法 目标
延迟（Latency） 测量单次推理时间（ms） 越低越好
吞吐量（Throughput） 测量批量处理时的每秒推理次数（FPS） 越高越好
精度验证 对比原始模型与TensorRT引擎的输出差异（如余弦相似度） 差异 < 1e-3
内存占用 监控GPU显存使用量 优化后应显著降低
最佳实践： 生产环境部署时，建议使用TensorRT的C++ API以获得最佳性能，并使用异步流（Stream）来重叠计算和数据传输。
