后训练量化 (Post-Training Quantization) 概述

后训练量化 (PTQ) 是一种在模型训练完成后，无需重新训练或微调，直接将预训练模型从浮点数转换为低精度整数表示的模型压缩技术。其核心目标是 减少模型存储空间、降低内存带宽需求、加速推理计算，同时尽可能保持模型精度。

PTQ 因其 简单、快速、无需训练数据标签 等优点，成为工业界部署深度学习模型的首选量化方案之一。

PTQ 核心流程详解

一个完整的 PTQ 流程包含以下几个关键步骤：

  1. 1模型准备：加载预训练的 FP32 模型，并将其转换为可量化的图表示（如 ONNX）。
  2. 2校准集选择与准备：准备一小部分无标签的代表性数据，用于分析激活值的分布。
  3. 3校准 (Calibration)：在校准数据上运行模型，收集各层激活值的统计信息（如最大值、最小值、直方图）。
  4. 4量化参数计算：根据收集的统计信息，为每一层计算量化参数：缩放因子 (Scale) 和 零点 (Zero Point)。
  5. 5模型转换：将 FP32 权重和激活值，使用计算出的量化参数，转换为 INT8 表示。
  6. 6精度验证与调优：在测试集上评估量化后模型的精度，若损失过大，需调整校准方法或量化策略。
💡 核心公式： 线性量化公式：Q = round(R / S) + Z，其中 R 为实数值，Q 为量化整数值，S 为缩放因子，Z 为零点。

校准集选择与使用指南

校准集的选择直接影响量化后模型的精度。其核心原则是：校准数据应能代表模型在实际推理中遇到的真实数据分布。

校准集选择原则

原则 说明 建议
代表性 数据分布应与测试集/真实场景一致 从训练集或真实数据中随机抽取
数据量 足够覆盖各层激活值的动态范围 通常 100-1000 个样本即可，无需标签
多样性 包含各类场景、光照、角度等变化 避免单一场景，确保分布全面
预处理一致性 与模型推理时的预处理完全相同 归一化、裁剪、尺寸等参数需一致

常见校准方法

  • 最大最小值法 (MinMax)：直接使用激活值的最大最小值确定范围。简单，但对异常值敏感。
  • 熵最小化法 (Entropy)：寻找使量化后信息损失最小的阈值。TensorRT 常用，精度较高。
  • 百分位数法 (Percentile)：例如使用 99.9% 分位数作为最大值，可排除极端异常值。
  • 均方误差最小化法 (MSE)：寻找使量化前后张量均方误差最小的缩放因子。

TensorRT PTQ API 实战

TensorRT 提供了强大的 PTQ 工具，主要通过 IInt8Calibrator 接口和 trt.BuilderFlag.INT8 标志实现。

关键步骤代码示例

import tensorrt as trt
import numpy as np

# 1. 定义校准器类
class MyCalibrator(trt.IInt8EntropyCalibrator2):
    def __init__(self, calibration_data):
        super().__init__()
        self.data = calibration_data  # 校准数据迭代器
        self.buffer = None
        self.count = 0
        
    def get_batch_size(self):
        return 1  # 校准批次大小
        
    def get_batch(self, names):
        try:
            batch = next(self.data)
            self.buffer = batch.ravel().astype(np.float32)
            self.count += 1
            return [int(self.buffer.data.ctypes.data)]
        except StopIteration:
            return None
            
    def read_calibration_cache(self):
        # 可读取缓存，加速后续校准
        return None
        
    def write_calibration_cache(self, cache):
        # 保存校准缓存
        with open("calibration.cache", "wb") as f:
            f.write(cache)

# 2. 构建 INT8 引擎
logger = trt.Logger(trt.Logger.WARNING)
builder = trt.Builder(logger)
network = builder.create_network(1 << int(trt.NetworkDefinitionCreationFlag.EXPLICIT_BATCH))
parser = trt.OnnxParser(network, logger)

# 解析 ONNX 模型
with open("model.onnx", "rb") as f:
    parser.parse(f.read())

# 配置 INT8 校准
config = builder.create_builder_config()
config.set_flag(trt.BuilderFlag.INT8)
config.set_memory_pool_limit(trt.MemoryPoolType.WORKSPACE, 1 << 30)  # 1GB

calibrator = MyCalibrator(calibration_data_generator())
config.int8_calibrator = calibrator

# 3. 构建并序列化引擎
engine = builder.build_engine(network, config)
with open("model_int8.engine", "wb") as f:
    f.write(engine.serialize())

PyTorch PTQ API 实战

PyTorch 从 1.8 版本开始提供 torch.quantization 模块，支持灵活的 PTQ 操作。

静态量化完整示例

import torch
import torch.nn as nn
import torch.quantization
from torch.quantization import quantize_dynamic, prepare, convert

# 1. 定义并加载预训练模型
model_fp32 = torchvision.models.resnet18(pretrained=True)
model_fp32.eval()

# 2. 准备校准数据（示例）
calibration_data = [torch.randn(1, 3, 224, 224) for _ in range(100)]

# 3. 模型融合（可选，提升性能）
model_fp32_fused = torch.quantization.fuse_modules(model_fp32, 
    [['conv1', 'bn1', 'relu']] + 
    [[f'layer{i}.{j}.conv1', f'layer{i}.{j}.bn1', f'layer{i}.{j}.relu'] 
     for i in range(1,5) for j in [0,1]]
)

# 4. 指定量化配置
model_fp32_fused.qconfig = torch.quantization.get_default_qconfig('fbgemm')  # x86 CPU
# model_fp32_fused.qconfig = torch.quantization.get_default_qconfig('qnnpack')  # ARM CPU

# 5. 准备模型（插入观察器）
model_prepared = prepare(model_fp32_fused)

# 6. 校准（运行校准数据）
with torch.no_grad():
    for data in calibration_data:
        model_prepared(data)

# 7. 转换为量化模型
model_int8 = convert(model_prepared)

# 8. 保存与加载量化模型
torch.save(model_int8.state_dict(), 'resnet18_int8.pth')

# 9. 动态量化示例（适用于LSTM、Linear等）
model_lstm = nn.LSTM(10, 20, 2)
model_lstm_quantized = quantize_dynamic(model_lstm, {nn.LSTM, nn.Linear}, dtype=torch.qint8)

精度评估与调优策略

量化后模型精度下降是常见问题，需系统评估并采取调优措施。

评估指标与方法

评估维度 具体指标 工具/方法
任务精度 Top-1/Top-5 Accuracy, mAP, F1-Score 在完整测试集上评估，对比 FP32 基线
逐层误差分析 MSE, Cosine Similarity, KL Divergence 比较量化前后各层输出张量
硬件性能 推理延迟 (Latency), 吞吐量 (Throughput) TensorRT Profiler, PyTorch Profiler
模型大小 磁盘占用 (MB), 内存占用 (MB) 直接对比模型文件大小

精度调优策略

  • 校准方法调优：尝试不同的校准算法（Entropy, MinMax, Percentile）。
  • 校准集增强：增加校准集数量或多样性，确保分布代表性。
  • 分层量化策略：对敏感层（如第一层、最后一层）保持 FP16 或更高精度。
  • 量化感知训练 (QAT)：当 PTQ 精度损失过大时（如 >3%），考虑使用 QAT 进行微调。
  • 模型结构优化：移除对量化不友好的操作（如大数值范围的激活函数）。
📊 精度损失容忍度参考： 通常，分类任务 Top-1 精度下降 <1% 为优秀，<2% 为可接受；检测/分割任务 mAP 下降 <2% 为优秀，<3% 为可接受。具体需根据业务需求确定。
