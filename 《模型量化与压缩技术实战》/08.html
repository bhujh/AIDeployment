一、INT8量化概述

INT8量化是一种将浮点模型（通常是FP32）转换为8位整数表示的模型压缩技术。它能显著减少模型大小、降低内存占用、加速推理过程，同时保持可接受的精度损失。这是移动端和边缘设备部署深度学习模型的关键技术。

核心价值： 在资源受限的设备上实现高效推理，平衡性能、功耗与精度。

二、完整转换流程详解

INT8量化转换通常包含以下关键步骤，我们将以TensorRT/PyTorch为例进行说明。

1

准备FP32预训练模型

加载已经训练好的浮点模型，并确保其处于评估模式。

2

校准数据集准备

准备具有代表性的校准数据集（通常100-500张图片），用于确定各层的动态范围。

3

校准与量化

通过校准过程确定每层激活值和权值的缩放因子(scale)和零点(zero point)。

4

模型转换与序列化

将量化后的模型转换为目标框架格式（如TensorRT engine、TFLite等）并保存。

代码示例：PyTorch静态量化

import torch
import torchvision
import torch.quantization

# 1. 加载预训练FP32模型
model_fp32 = torchvision.models.resnet18(pretrained=True)
model_fp32.eval()

# 2. 准备量化配置
model_fp32.qconfig = torch.quantization.get_default_qconfig('fbgemm')
model_fp32_prepared = torch.quantization.prepare(model_fp32)

# 3. 使用校准数据集进行校准
def calibrate_model(model, data_loader):
    model.eval()
    with torch.no_grad():
        for data, target in data_loader:
            model(data)

# 假设calibration_loader是校准数据加载器
calibrate_model(model_fp32_prepared, calibration_loader)

# 4. 转换为INT8模型
model_int8 = torch.quantization.convert(model_fp32_prepared)

# 5. 保存量化模型
torch.save(model_int8.state_dict(), 'resnet18_int8.pth')
print("INT8量化模型保存成功！")
注意： 不同框架（TensorFlow、PyTorch、ONNX Runtime）的量化API略有不同，但核心原理一致。

Android端部署示例代码

// Kotlin代码示例 - 使用TFLite加载INT8模型
class TFLiteClassifier(context: Context) {
    private var interpreter: Interpreter
    
    init {
        // 1. 加载INT8量化模型
        val modelFile = loadModelFile(context, "model_int8_quant.tflite")
        val options = Interpreter.Options()
        options.setUseNNAPI(true) // 启用NNAPI加速
        
        // 2. 创建解释器
        interpreter = Interpreter(modelFile, options)
    }
    
    fun classify(inputData: ByteBuffer): FloatArray {
        // 3. 准备输出
        val output = Array(1) { FloatArray(1000) }
        
        // 4. 运行推理 (INT8输入/输出)
        interpreter.run(inputData, output)
        
        return output[0]
    }
    
    private fun loadModelFile(context: Context, filename: String): MappedByteBuffer {
        val fileDescriptor = context.assets.openFd(filename)
        val inputStream = FileInputStream(fileDescriptor.fileDescriptor)
        return inputStream.channel.map(
            FileChannel.MapMode.READ_ONLY,
            fileDescriptor.startOffset,
            fileDescriptor.declaredLength
        )
    }
}

基准测试脚本示例

import time
import numpy as np
import psutil  # 用于监控资源

def benchmark_model(model, input_tensor, num_runs=100):
    """基准测试函数"""
    # 预热
    for _ in range(10):
        _ = model(input_tensor)
    
    # 记录开始时间
    start_time = time.time()
    start_memory = psutil.Process().memory_info().rss / 1024 / 1024  # MB
    
    # 运行多次推理
    for _ in range(num_runs):
        outputs = model(input_tensor)
    
    # 计算统计信息
    end_time = time.time()
    end_memory = psutil.Process().memory_info().rss / 1024 / 1024
    
    avg_latency = (end_time - start_time) * 1000 / num_runs  # 毫秒
    memory_used = end_memory - start_memory
    
    print(f"平均延迟: {avg_latency:.2f} ms")
    print(f"内存占用变化: {memory_used:.2f} MB")
    print(f"吞吐量: {1000/avg_latency:.2f} FPS")
    
    return avg_latency, memory_used

# 对比测试FP32和INT8模型
print("=== FP32模型基准测试 ===")
fp32_latency, fp32_memory = benchmark_model(model_fp32, dummy_input)

五、最佳实践与注意事项

  • 校准数据集选择： 必须具有代表性，最好来自真实应用场景的分布。
  • 敏感层处理： 第一层和最后一层对量化敏感，可考虑保持FP16精度。
  • 精度验证： 必须在完整的验证集上测试量化后的精度，确保满足应用要求。
  • 硬件兼容性： 确认目标硬件支持INT8指令集（如ARM的Dot Product指令）。
  • 量化感知训练： 对于精度要求高的场景，建议使用量化感知训练而非训练后量化。
  • 动态范围调整： 对于激活值分布不均匀的层，可使用每通道量化(per-channel)。
经验法则： 对于大多数视觉任务，INT8量化可将模型大小减少4倍，推理速度提升2-3倍，精度损失通常小于1%。
