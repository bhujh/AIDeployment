结构化剪枝实战

模型量化与压缩技术实战 · 第十章

通道剪枝、滤波器剪枝、使用PyTorch实现与微调

一、结构化剪枝概述

结构化剪枝是一种模型压缩技术，它通过移除神经网络中完整的结构单元（如通道、滤波器、神经元块）来减少模型大小和计算量。与细粒度剪枝（移除单个权重）不同，结构化剪枝直接产生硬件友好的规整网络结构，无需特殊硬件或库支持即可加速。

核心优势：

  • 硬件友好：剪枝后仍是规整的矩阵运算，可直接利用现有深度学习框架和硬件加速。
  • 加速明显：直接减少FLOPs和内存占用，推理速度提升显著。
  • 易于微调：剪枝后的模型结构完整，便于使用少量数据快速恢复精度。

二、通道剪枝与滤波器剪枝

结构化剪枝的两个主要方向：通道剪枝（Channel Pruning）和滤波器剪枝（Filter Pruning）。

2.1 通道剪枝 (Channel Pruning)

针对卷积层的输出通道进行剪枝。移除一个输出通道，意味着移除该通道对应的所有滤波器，以及下一层中与该通道相连的所有输入通道。

实现要点：通常基于通道的重要性评分（如L1范数、BN层缩放因子）进行排序，移除评分低的通道。

2.2 滤波器剪枝 (Filter Pruning)

本质与通道剪枝类似，但视角不同。滤波器剪枝直接移除整个滤波器（即3D权重张量），从而同时减少输出通道和下一层的输入通道。

对比项 通道剪枝 滤波器剪枝
操作对象 输出通道（Output Channel） 整个滤波器（Filter）
影响范围 当前层和下一层 当前层和下一层
重要性评估 通道激活值、BN层γ系数 滤波器权重范数、特征图重要性
实现复杂度 中等 中等
典型方法 ThiNet, Channel Pruning Pruning Filters, FPGM

三、使用PyTorch实现结构化剪枝

以下是一个基于滤波器L1范数的结构化剪枝PyTorch实现示例。

import torch
import torch.nn as nn
import torch.nn.utils.prune as prune
import numpy as np

class StructuredFilterPruner:
    """
    基于L1范数的滤波器结构化剪枝器
    """
    def __init__(self, model, prune_ratio=0.3):
        """
        Args:
            model: 要剪枝的PyTorch模型
            prune_ratio: 目标剪枝比例（每层）
        """
        self.model = model
        self.prune_ratio = prune_ratio
        self.masks = {}  # 存储剪枝掩码

    def compute_filter_importance(self, conv_layer):
        """计算滤波器重要性（L1范数）"""
        return torch.norm(conv_layer.weight.data, p=1, dim=(1, 2, 3))

    def prune_conv_layer(self, conv_layer, layer_name):
        """对单个卷积层进行滤波器剪枝"""
        importance = self.compute_filter_importance(conv_layer)
        num_filters = len(importance)
        num_prune = int(self.prune_ratio * num_filters)

        if num_prune == 0:
            return None

        # 选择重要性最低的滤波器索引
        prune_indices = torch.argsort(importance)[:num_prune].tolist()
        keep_indices = [i for i in range(num_filters) if i not in prune_indices]

        # 创建掩码（1保留，0剪枝）
        mask = torch.ones(num_filters, dtype=torch.bool)
        mask[prune_indices] = 0
        self.masks[layer_name] = mask

        # 应用掩码：直接移除权重（实际中常创建新层）
        pruned_weight = conv_layer.weight.data[keep_indices, :, :, :].clone()
        if conv_layer.bias is not None:
            pruned_bias = conv_layer.bias.data[keep_indices].clone()
        else:
            pruned_bias = None

        # 创建新的卷积层（输出通道数减少）
        pruned_conv = nn.Conv2d(
            in_channels=conv_layer.in_channels,
            out_channels=len(keep_indices),
            kernel_size=conv_layer.kernel_size,
            stride=conv_layer.stride,
            padding=conv_layer.padding,
            dilation=conv_layer.dilation,
            groups=conv_layer.groups,
            bias=conv_layer.bias is not None
        )
        pruned_conv.weight.data = pruned_weight
        if pruned_bias is not None:
            pruned_conv.bias.data = pruned_bias

        return pruned_conv

    def prune_model(self):
        """遍历并剪枝模型中的所有卷积层"""
        pruned_model = self.model
        for name, module in self.model.named_modules():
            if isinstance(module, nn.Conv2d):
                print(f"Pruning layer: {name}")
                pruned_conv = self.prune_conv_layer(module, name)
                if pruned_conv is not None:
                    # 替换原层（实际中需要递归替换，此处为简化示例）
                    setattr(self.model, name.split('.')[-1], pruned_conv)
        return self.model

# 使用示例
if __name__ == "__main__":
    # 假设有一个简单的CNN模型
    class SimpleCNN(nn.Module):
        def __init__(self):
            super().__init__()
            self.conv1 = nn.Conv2d(3, 32, 3, padding=1)
            self.conv2 = nn.Conv2d(32, 64, 3, padding=1)
            self.fc = nn.Linear(64 * 28 * 28, 10)

        def forward(self, x):
            x = torch.relu(self.conv1(x))
            x = torch.relu(self.conv2(x))
            x = x.view(x.size(0), -1)
            return self.fc(x)

    model = SimpleCNN()
    print("原始模型 conv2 输出通道数:", model.conv2.out_channels)

    pruner = StructuredFilterPruner(model, prune_ratio=0.5)
    pruned_model = pruner.prune_model()

    print("剪枝后模型 conv2 输出通道数:", pruned_model.conv2.out_channels)
    print("剪枝完成！")
注意：上述示例为教学演示，实际应用中需要考虑下一层输入通道的同步调整、BN层的适配以及更复杂的重要性评估策略。

四、剪枝后的模型微调

剪枝操作会不可避免地造成模型精度损失，微调（Fine-tuning）是恢复精度的关键步骤。

4.1 微调策略

  1. 学习率调整：使用较小的学习率（如原始学习率的1/10），避免破坏已学到的有用特征。
  2. 训练周期：通常需要较少的epoch（10-20%的原训练周期）即可恢复大部分精度。
  3. 数据使用：可使用全部训练数据，或仅使用一个子集以加速微调过程。
  4. 冻结部分层：对于大型模型，可以冻结剪枝影响较小的层，只训练被剪枝层及其后续层。

4.2 PyTorch微调示例代码

import torch.optim as optim
from torch.utils.data import DataLoader

def fine_tune_pruned_model(model, train_loader, val_loader, epochs=10):
    """
    微调剪枝后的模型
    Args:
        model: 剪枝后的模型
        train_loader: 训练数据加载器
        val_loader: 验证数据加载器
        epochs: 微调轮数
    """
    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    model = model.to(device)

    # 使用较小的学习率和合适的优化器
    optimizer = optim.Adam(model.parameters(), lr=1e-4, weight_decay=1e-4)
    criterion = nn.CrossEntropyLoss()

    # 学习率调度器
    scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=epochs)

    print("开始微调...")
    for epoch in range(epochs):
        model.train()
        train_loss = 0.0
        correct = 0
        total = 0

        for batch_idx, (inputs, targets) in enumerate(train_loader):
            inputs, targets = inputs.to(device), targets.to(device)

            optimizer.zero_grad()
            outputs = model(inputs)
            loss = criterion(outputs, targets)
            loss.backward()
            optimizer.step()

            train_loss += loss.item()
            _, predicted = outputs.max(1)
            total += targets.size(0)
            correct += predicted.eq(targets).sum().item()

        # 验证
        model.eval()
        val_correct = 0
        val_total = 0
        with torch.no_grad():
            for inputs, targets in val_loader:
                inputs, targets = inputs.to(device), targets.to(device)
                outputs = model(inputs)
                _, predicted = outputs.max(1)
                val_total += targets.size(0)
                val_correct += predicted.eq(targets).sum().item()

        scheduler.step()

        print(f"Epoch [{epoch+1}/{epochs}] | "
              f"Train Loss: {train_loss/(batch_idx+1):.4f} | "
              f"Train Acc: {100.*correct/total:.2f}% | "
              f"Val Acc: {100.*val_correct/val_total:.2f}%")

    print("微调完成！")
    return model

4.3 微调效果预期

经过适当的微调，结构化剪枝模型通常能达到：

  • 精度恢复：在图像分类任务上，可恢复至原模型精度的98%-99.5%。
  • 速度提升：FLOPs减少30%-50%，推理速度提升1.5-2倍。
  • 模型缩小：参数量减少30%-60%，模型文件显著减小。

五、实战流程总结

步骤 关键操作 常用工具/指标
1. 基准模型 训练原始模型，获取基准精度和大小 PyTorch/TensorFlow, Accuracy, FLOPs
2. 评估重要性 计算每个滤波器/通道的重要性分数 L1/L2范数, BN γ系数, 特征图激活
3. 执行剪枝 按比例移除低重要性结构，重建模型 自定义剪枝器, Torch Prune
4. 模型微调 使用小学习率训练剪枝后模型 Adam/SGD, CosineAnnealingLR
5. 部署评估 测试最终精度、速度、模型大小 ONNX, TensorRT, 推理时间
